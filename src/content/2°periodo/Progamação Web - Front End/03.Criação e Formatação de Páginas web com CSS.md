## Criação e Formatação de Páginas Web com CSS**

### 1. **Introdução ao CSS**
- CSS controla a **aparência e formatação** de uma página web.
- Separação entre **conteúdo (HTML)** e **estilo (CSS)**.
- Versão atual: **CSS3**. CSS4 está em desenvolvimento modular.

---

### 2. **Regras CSS e Seletores**
- **Estrutura de uma regra CSS**:
  ```css
  seletor {
    propriedade: valor;
  }
  ```
- **Seletores comuns**:
  - **Tipo**: `h1 { ... }`
  - **Universal**: `* { ... }`
  - **Classe**: `.minha-classe { ... }`
  - **ID**: `#meu-id { ... }`

---

### 3. **Sintaxe e Estilo CSS**
- Use `<style>` no `<head>` para CSS interno.
- Sempre use **ponto e vírgula** e **chaves** corretamente.
- Formate regras longas em múltiplas linhas para legibilidade.

---

### 4. **Seletores de Classe e ID**
- **Classe**: Pode ser usada em vários elementos.
  ```html
  <p class="destaque">Texto</p>
  ```
- **ID**: Deve ser único na página.
  ```html
  <h1 id="titulo-principal">Título</h1>
  ```

---

### 5. **Elementos `span` e `div`**
- **`span`**: Elemento inline (dentro do texto).
- **`div`**: Elemento de bloco (quebra de linha).
- Ambos são **genéricos** e usados para aplicar CSS.

---

### 6. **Cascading (Cascata)**
- Ordem de prioridade CSS:
  1. Estilo inline (`style=""`)
  2. Tag `<style>`
  3. Arquivo CSS externo
  4. Configurações do usuário
  5. Padrões do navegador

---

### 7. **Arquivos CSS Externos**
- Use a tag `<link>` para vincular:
  ```html
  <link rel="stylesheet" href="estilo.css">
  ```
- Vantagens: Reutilização, organização, manutenção.

---

### 8. **Propriedades CSS Comuns**
- **`color`**: Cor do texto
- **`background-color`**: Cor de fundo
- **`font-family`**, **`font-size`**: Fonte
- **`text-align`**: Alinhamento
- **`width`**, **`height`**: Largura e altura

---

### 9. **Box Model**
Cada elemento é uma **caixa** com:
- **Conteúdo**
- **Padding** (espaço interno)
- **Border** (borda)
- **Margin** (espaço externo)

Exemplo:
```css
div {
  padding: 20px;
  margin: 10px;
  border: 1px solid black;
}
```

---

### 10. **Propriedades de Margem e Preenchimento**
- **`margin`**: Espaço externo
- **`padding`**: Espaço interno
- Podem ser definidas por lado:
  - `margin-top`, `padding-left`, etc.

---

### 11. **Border Radius e Display**
- **`border-radius`**: Cantos arredondados
  ```css
  button {
    border-radius: 10px;
  }
  ```
- **`display`**: Controla o layout
  - `block`, `inline`, `inline-block`, `none`

---

### 12. **Viewport e Design Responsivo**
- Use a meta tag viewport para mobile:
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  ```
- **Media Queries**: Adaptam o layout a diferentes telas.

---

### 13. **Ferramentas e Validação**
- **Validador CSS da W3C**: [jigsaw.w3.org/css-validator](https://jigsaw.w3.org/css-validator)
- **MDN Web Docs**: Referência completa de CSS.

---

### 14. **Conclusão**
- CSS é essencial para o **design moderno** e **experiência do usuário**.
- Use **seletores**, **classes**, **IDs**, **box model**, e **arquivos externos** para criar páginas bem estruturadas e estilizadas.
