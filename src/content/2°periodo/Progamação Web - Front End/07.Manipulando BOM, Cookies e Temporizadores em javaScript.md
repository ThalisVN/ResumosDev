## Manipulando BOM, Cookie e Temporizadores em JavaScript

###  **1. Browser Object Model (BOM)**

O **BOM** é o conjunto de objetos que permite ao JavaScript interagir com o navegador.  
O objeto principal é o **`window`**, considerado o objeto global — todas as variáveis e funções globais se tornam suas propriedades.

#### Principais métodos e propriedades:

- **`window.innerWidth` / `innerHeight`** → tamanho interno da janela.
    
- **`window.open(url, nome, propriedades)`** → abre uma nova janela ou aba.
    
- **`window.alert()`, `window.confirm()`, `window.prompt()`** → exibem caixas de diálogo (alerta, confirmação e entrada de dados).
    
- **`window.setTimeout()`** → executa uma função após um tempo definido.
    
- **`window.setInterval()`** → executa uma função repetidamente em intervalos fixos.
    
- **`window.clearTimeout()` / `clearInterval()`** → cancelam os temporizadores.
    

Outros métodos:

- **`resizeTo()`** (redimensionar janela), **`moveTo()`** (mover janela), **`close()`** (fechar janela).
    

---

###  **2. Outros Objetos do BOM**

- **`navigator`** → informações sobre o navegador (ex.: `userAgent` identifica o navegador).
    
- **`screen`** → dados sobre a tela (resolução, cor, largura, altura, etc.).
    
- **`history`** → permite navegar no histórico com:
    
    - `back()` → volta uma página.
        
    - `forward()` → avança uma página.
        
    - `go(n)` → vai a uma posição específica do histórico.
        

🔹 **Diferença entre BOM e DOM:**  
O **BOM** representa o navegador e seus recursos, enquanto o **DOM** representa o documento HTML exibido na janela (o DOM é parte do BOM).

---

###  **3. Cookies**

Os **cookies** são pequenos arquivos de texto armazenados pelo navegador para manter informações entre páginas (como login e preferências).

Cada cookie contém:

- `name=value` → par chave-valor
    
- `expires` → data de expiração
    
- `domain` → domínio ao qual pertence
    
- `path` → caminho de acesso
    
- `secure` → indica se deve ser usado apenas em conexões seguras (HTTPS)
    

#### Manipulação em JavaScript:

- **Criar:** `document.cookie = "nome=valor; expires=data; path=/";`
    
- **Ler:** `document.cookie` retorna todos os cookies da página.
    
- **Alterar:** recriar com o mesmo nome e novo valor.
    
- **Apagar:** definir uma data de expiração no passado.
    

Funções comuns:

- `criarCookie(nome, valor, dias)`
    
- `retornarCookie(nome)`
    
- `checarCookie()` → verifica se existe um cookie e exibe mensagens personalizadas.
    

⚖️ **Observação legal:** O uso de cookies exige consentimento do usuário (Lei Geral de Proteção de Dados – LGPD).

---

###  **4. Temporizadores e Event Loop**

- O **`setTimeout()`** executa uma função uma única vez após o tempo definido.
    
- O **`setInterval()`** executa repetidamente.  
    Esses métodos funcionam com o **event loop**, que controla a fila de tarefas do JavaScript, permitindo a execução assíncrona sem bloquear o código principal.
    

---

###  **5. Conclusão**

O BOM é essencial para o controle de janelas, histórico e ambiente do navegador.  
Os **temporizadores** permitem ações controladas por tempo, e os **cookies** são fundamentais para manter sessões e preferências do usuário.  
Esses conceitos tornam o JavaScript mais interativo e dinâmico no desenvolvimento web.
