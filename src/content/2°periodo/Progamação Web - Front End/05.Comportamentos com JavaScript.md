## **Comportamento com javascript**
### **1. Introdução**

- JavaScript é uma **linguagem interpretada**, leve e acessível, usada para adicionar comportamento às páginas web.
    
- O **DOM (Document Object Model)** permite acessar e manipular elementos HTML (tags, IDs, classes) dinamicamente.
    
- Eventos como cliques ou movimentos do mouse conectam interações do usuário a ações no navegador.
    

---

### **2. Sintaxe e Estrutura**

- É **case-sensitive** e usa o estilo **camelCase** (ex: `getElementById`).
    
- Scripts podem ser colocados no `<head>` ou no fim do `<body>` (melhor desempenho).
    
- Três formas de **saída**:
    
    - `document.writeln()` – mostra conteúdo ao carregar a página.
        
    - `alert()` – exibe mensagens em janelas pop-up.
        
    - `innerHTML`/`getElementById()` – altera dinamicamente o conteúdo da página.
        

---

### **3. Entradas e Eventos**

- Eventos conectam ações a funções: `onClick`, `onKeyUp`, `onLoad`, etc.
    
- `onClick` chama funções ao clicar em elementos.
    
- `onKeyUp` permite capturar e exibir o que o usuário digita em tempo real.
    
- JavaScript é **orientado a eventos**, executando código apenas quando algo acontece.
    

---

### **4. Comentários**

- `//` para comentários de linha.
    
- `/* ... */` para blocos de comentários.
    

---

### **5. Variáveis**

- Declaradas com `var`, `let` ou `const`.
    
- Não precisam de tipo definido (linguagem **dinamicamente tipada**).
    
- Funções também podem ser tratadas como variáveis.
    
- **Escopo:** variáveis podem ser globais ou locais.
    
- **Palavras-chave especiais:** `NaN`, `Infinity`, `null`, `true`, `false`, `undefined`.
    

---

### **6. Operadores**

- **Aritméticos:** `+`, `-`, `*`, `/`, `%`, `++`, `--`.
    
- **Lógicos e de comparação:** `==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`, `&&`, `||`, `!`.
    
- `==` compara valores; `===` compara valores e tipos.
    

---

### **7. Estruturas Condicionais**

- **if / else / else if** – executam blocos de código conforme condições.
    
- **switch** – alternativa mais organizada para múltiplas condições.
    
- **Operador ternário:** `condição ? valorSeVerdadeiro : valorSeFalso`.
    

---

### **8. Laços de Repetição**

- **for**, **for/in**, **while** e **do/while**.
    
- `for/in` percorre propriedades de objetos.
    
- `typeof` ajuda a identificar o tipo de dados.
    

---

- Usa uma **função JavaScript** para modificar o conteúdo do elemento HTML via `getElementById` e `outerHTML`.
    
- Mostra como o JavaScript interage com o DOM para criar **páginas dinâmicas**.
    

---

### **10. Boas Práticas**

- Usar nomes descritivos para variáveis (ex: `mensagemInicial`).
    
- Seguir convenções de **camelCase**.
    
- Encerrar instruções com `;`. (não é obrigatório)
    
- Separar código em arquivos externos `.js` para organização.
    

---

### **11. Conclusão**

O JavaScript é uma linguagem essencial para o **Front-End**, permitindo criar **interatividade e dinamismo** nas páginas. Com ele, é possível manipular elementos HTML, reagir a eventos e construir experiências de usuário ricas e responsivas.
