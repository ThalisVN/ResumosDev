##  **Criação de  Vínculos e Formulários**

### 1. **Introdução**
- **Links** permitem navegação entre páginas e recursos.
- **Formulários** permitem interação do usuário com o servidor.
- HTML5 introduziu novos tipos de entrada e validação.

---

### 2. **Elemento `<a>` (Link)**
- Sintaxe básica:
  ```html
  <a href="URL">Texto do link</a>
  ```
- Atributo `download` para baixar arquivos:
  ```html
  <a href="arquivo.pdf" download>Baixar PDF</a>
  ```

---

### 3. **URLs Relativos e Absolutos**

- **URL relativo**: Navega para recursos dentro do mesmo servidor, usando caminhos a partir do local atual.
  - Exemplo: `href="pagina2.html"`
  - Exemplo para subir um nível: `href="../outra-pasta/pagina3.html"`
  - Exemplo para acessar subdiretório: `href="pasta/arquivo.html"`

- **URL absoluto**: Caminho completo a partir do diretório raiz do servidor ou URL completa.
  - Exemplo com caminho absoluto no servidor: `href="/projeto/pagina2.html"`
  - Exemplo com URL completa: `href="https://www.exemplo.com/projeto/pagina2.html"`

- **Uso de `../`**: 
  - Cada `../` sobe um nível no diretório
  - Exemplo: `href="../../pasta-superior/arquivo.html"` sobe dois níveis

- **URL relativo de caminho absoluto**: 
  - Começa com `/` e é relativo ao diretório raiz do servidor
  - Exemplo: `href="/imagens/logo.png"`
---

### 4. **Arquivo `index.html`**
- É o arquivo padrão carregado quando um diretório é acessado.
- Nomes alternativos: `index.htm`, `default.htm` (em servidores Microsoft IIS).

---

### 5. **CSS para Links**
- Estilização de estados de link:
  ```css
  a:link { color: blue; }      /* Não visitado */
  a:visited { color: purple; } /* Visitado */
  a:hover { text-decoration: underline; } /* Mouse sobre */
  ```
- Remover sublinhado:
  ```css
  a { text-decoration: none; }
  ```

---

### 6. **Processamento de Formulários**
- Dados são enviados como pares `nome=valor`.
- Métodos:
  - `method="post"`: Envia dados como documento de texto.
  - `method="get"`: Usado em buscas (dados na URL).
- `action`: Define para onde os dados são enviados (URL ou e-mail).

---

### 7. **Elementos de Formulário**

#### ✅ **Campos de Texto**
- Linha única:
  ```html
  <input type="text" name="usuario" size="40" maxlength="30">
  ```
- Multilinha:
  ```html
  <textarea name="comentario" rows="5" cols="50"></textarea>
  ```

#### ✅ **Botões de Rádio**
- Apenas uma opção pode ser selecionada:
  ```html
  <input type="radio" name="genero" value="masculino"> Masculino
  <input type="radio" name="genero" value="feminino"> Feminino
  ```

#### ✅ **Caixas de Seleção (Checkbox)**
- Múltiplas opções podem ser selecionadas:
  ```html
  <input type="checkbox" name="interesse" value="filmes"> Filmes
  ```

#### ✅ **Menus Suspensos e Listas**
- Menu suspenso:
  ```html
  <select name="cor">
    <option value="vermelho">Vermelho</option>
  </select>
  ```
- Lista de rolagem:
  ```html
  <select name="cor" size="3" multiple>
    <option value="vermelho">Vermelho</option>
  </select>
  ```

#### ✅ **Botões de Envio e Reset**
- Enviar:
  ```html
  <input type="submit" value="Enviar">
  ```
- Reset:
  ```html
  <input type="reset" value="Limpar">
  ```

---

### 8. **Novos Tipos de Entrada no HTML5**

#### 🔍 **Busca**
```html
<input type="search" name="q">
```

#### 🌐 **URL**
```html
<input type="url" name="site">
```

#### 📅 **Data e Hora**
```html
<input type="date" name="data">
<input type="time" name="hora">
```

#### 🎨 **Cor**
```html
<input type="color" name="corfavorita">
```

#### 🔢 **Número e Controle Deslizante**
- Número:
  ```html
  <input type="number" name="idade" min="0" max="120" step="1">
  ```
- Controle deslizante:
  ```html
  <input type="range" name="volume" min="0" max="100">
  ```

---

### 9. **Web Design: UI e UX**
- **UI (Interface do Usuário)**: Elementos visuais (cores, fontes, botões).
- **UX (Experiência do Usuário)**: Sensação e facilidade de uso.
- Dicas:
  - Use cores contrastantes.
  - Mantenha a consistência.
  - Evite poluição visual.
  - Otimize tempo de carregamento.

---

### 10. **Navegação Interna com Links Âncora**
- Link para seção na mesma página:
  ```html
  <a href="#secao2">Ir para Seção 2</a>
  ...
  <h2 id="secao2">Seção 2</h2>
  ```

---

### 11. **Estruturas de Navegação**
- **Linear**: Páginas em sequência (ex.: tutorial).
- **Hierárquica**: Página inicial com links para subpáginas.
- **Mista**: Combinação de hierarquia e links cruzados.

---

### 12. **Exemplo Prático: Página do Convento da Penha**
- Uso de links internos para navegação.
- CSS para layout com `display: table` e `display: cell`.
- Estilização de barra de navegação e conteúdo.

---

###  **Conclusão**
- Links e formulários são fundamentais para a **interatividade** e **navegação**.
- HTML5 trouxe **novos tipos de entrada** que melhoram a experiência do usuário.
- **UI/UX** são cruciais para a aceitação e usabilidade do site.
