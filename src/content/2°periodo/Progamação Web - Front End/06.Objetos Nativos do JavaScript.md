## Objetos Nativos do Javascript

### **1. Introdução**  
Os objetos nativos são fundamentais para o JavaScript. Eles podem ser usados como **construtores** (`String()`, `Number()`, `Boolean()`) ou como **valores primitivos** (`'texto'`, `123`, `true`).

---

### **2. String**  
Permite manipular textos.  
Principais propriedades e métodos:

- `length` → comprimento da string.
    
- `charAt()`, `charCodeAt()` → acessam caracteres individuais.
    
- `indexOf()`, `lastIndexOf()` → localizam substrings.
    
- `slice()`, `substring()`, `substr()` → extraem partes da string.
    
- `toUpperCase()`, `toLowerCase()` → mudam o caso.
    
- Métodos HTML como `bold()`, `italics()`, `link()` geram trechos formatados.
    

---

### **3. Array**  
Usado para armazenar listas de valores.  
Métodos principais:

- `push()`, `pop()`, `shift()`, `unshift()` → adicionam/removem itens.
    
- `map()` → cria novo array com base em uma função.
    
- `filter()` → retorna elementos que passam em uma condição.
    
- `concat()` → junta arrays.
    
- `reverse()`, `sort()` → ordenam ou invertem.  
    Inclui exemplos com **arrow functions**.
    

---

### **4. Date**  
Manipula datas e horários.

- Construtores como `new Date()`, `new Date(ano, mês, dia)` etc.
    
- Métodos `getDate()`, `getMonth()`, `getFullYear()`, `setDate()` etc.
    
- Permite comparar datas e formatar com `toLocaleString()`.
    

---

### **5. Math**  
Fornece funções matemáticas.  
Não precisa de `new`.  
Principais métodos:

- `abs()`, `ceil()`, `floor()`, `round()` → arredondamentos.
    
- `pow()`, `sqrt()` → potências e raízes.
    
- `random()` → números aleatórios.
    
- Constantes como `PI`, `E`, `SQRT2`.
    

---

### **6. Number**  
Trabalha com valores numéricos.  
Propriedades:

- `MAX_VALUE`, `MIN_VALUE`, `NaN`, `POSITIVE_INFINITY`, `NEGATIVE_INFINITY`.
    

---

### **7. Boolean**  
Representa valores lógicos: `true` ou `false`.

---

### **8. Conclusão**  
O JavaScript oferece diversos **objetos nativos** que facilitam o trabalho com **textos, números, vetores, datas e operações matemáticas**, tornando o código mais produtivo e expressivo.
