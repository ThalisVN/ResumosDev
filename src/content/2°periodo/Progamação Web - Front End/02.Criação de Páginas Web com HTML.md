## Criação de Páginas Web com HTML**

### 1. **Introdução**
- A **Web (World Wide Web)** é uma coleção de páginas interligadas.
- Uma **página web** exibe conteúdo como texto, imagens e elementos interativos.
- O **endereço de uma página** é sua **URL**.

---

### 2. **Criação de um Site**
Para criar um site, são necessários:
- **Editor de texto** (ex.: VS Code, Atom, Dreamweaver)
- **Ferramenta de upload** (ex.: FileZilla ou painel do provedor)
- **Serviço de hospedagem** (ex.: GitHub Pages, GoDaddy)
- **Navegador** (ex.: Chrome, Firefox)

---

### 3. **Estrutura Básica de uma Página HTML**
- **`<!DOCTYPE html>`**: Define o tipo de documento como HTML5.
- **`<html lang="pt-br">`**: Elemento raiz, com atributo de idioma.
- **`<head>`**: Contém metadados (título, codificação, autor, etc.).
- **`<body>`**: Contém o conteúdo visível da página.

Exemplo de esqueleto:
```html
<!DOCTYPE html>
<html lang="pt-br">
<head>
  <meta charset="UTF-8">
  <title>Minha Página</title>
</head>
<body>
  <!-- Conteúdo aqui -->
</body>
</html>
```

---

### 4. **Elementos Estruturais e Semânticos**
- **`<header>`**: Cabeçalho da página ou seção.
- **`<nav>`**: Menu de navegação.
- **`<main>`**: Conteúdo principal.
- **`<article>`**: Conteúdo independente (ex.: post de blog).
- **`<section>`**: Agrupamento temático.
- **`<aside>`**: Conteúdo complementar (ex.: sidebar).
- **`<footer>`**: Rodapé.

---

### 5. **Elementos de Conteúdo Comuns**
- **`<h1>` a `<h6>`**: Títulos.
- **`<p>`**: Parágrafo.
- **`<br>`**: Quebra de linha.
- **`<hr>`**: Linha horizontal.
- **`<div>`**: Divisão genérica.
- **`<strong>` ou `<b>`**: Negrito (semântico e não semântico).
- **`<em>` ou `<i>`**: Itálico (semântico e não semântico).

---

### 6. **Listas**
- **Lista não ordenada** (`<ul>` com `<li>`):
  ```html
  <ul>
    <li>Item 1</li>
    <li>Item 2</li>
  </ul>
  ```
- **Lista ordenada** (`<ol>` com `<li>`):
  ```html
  <ol>
    <li>Primeiro</li>
    <li>Segundo</li>
  </ol>
  ```

---

### 7. **Tabelas**
- **`<table>`**: Tabela.
- **`<tr>`**: Linha.
- **`<th>`**: Cabeçalho.
- **`<td>`**: Célula de dados.
- **`<caption>`**: Legenda da tabela.

Exemplo:
```html
<table>
  <caption>Desastres Eólicos</caption>
  <tr>
    <th>Tornados</th>
    <th>Furacões</th>
  </tr>
  <tr>
    <td>EF5</td>
    <td>Categoria 5</td>
  </tr>
</table>
```

---

### 8. **Links e Navegação**
- **`<a href="url">Link</a>`**: Link para outra página.
- **`<a href="#id">Link interno</a>`**: Link para seção da mesma página.
- Exemplo de link interno:
  ```html
  <a href="#secao1">Ir para Seção 1</a>
  ...
  <h2 id="secao1">Seção 1</h2>
  ```

---

### 9. **Metadados no `<head>`**
- **`<meta charset="UTF-8">`**: Define a codificação.
- **`<meta name="author" content="Nome">`**: Autor da página.
- **`<meta name="description" content="...">`**: Descrição para SEO.
- **`<title>`**: Título da aba do navegador.

---

### 10. **Conclusão**
- HTML é a base de toda página web.
- Uso de **elementos semânticos** melhora acessibilidade e SEO.
- Estrutura básica: `doctype`, `html`, `head`, `body`.
- Elementos comuns: textos, listas, tabelas, links, metadados.
