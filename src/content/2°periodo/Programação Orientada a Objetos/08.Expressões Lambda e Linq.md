## Expressões Lambda e Linq

### 1. Introdução
O documento aborda recursos avançados da linguagem C#, focando em expressões lambda, métodos de extensão, tipos anônimos e LINQ (Language Integrated Query). Essas ferramentas são essenciais para escrever código conciso, legível e alinhado com os princípios da programação funcional e orientada a objetos.

---

### 2. Expressões Lambda
- **Definição**: Funções anônimas que usam o operador `=>` ("vai para").  
  - **Sintaxe**: `(parâmetros) => expressão` ou `(parâmetros) => { bloco de código }`.  
  - **Exemplo**:  
    ```csharp
    var numerosPares = numeros.FindAll(x => x % 2 == 0);
    ```  
    Filtra números pares de uma lista.

- **Aplicações**:
  - Filtragem (`FindAll`), transformação (`Select`), ordenação (`OrderBy`).
  - Uso com delegates como `Func` e `Action`:
    ```csharp
    Func<int, bool> intFunc = x => x < 10;
    bool resultado = intFunc(5); // Retorna true
    ```

---

### 3. Métodos de Extensão
- **Propósito**: Adicionar funcionalidades a tipos existentes sem modificar seu código-fonte ou usar herança.  
- **Sintaxe**:  
  ```csharp
  public static int WordCount(this string str) => str.Split(new[] {' '}, StringSplitOptions.RemoveEmptyEntries).Length;
  ```  
  - **Uso**:  
    ```csharp
    string texto = "Hello world";
    int count = texto.WordCount(); // Retorna 2
    ```

---

### 4. Tipos Anônimos
- **Definição**: Classes temporárias criadas em tempo de compilação para armazenar dados de forma simples.  
- **Exemplo**:  
  ```csharp
  var carro = new { Marca = "Toyota", Cor = "Azul", Velocidade = 180 };
  Console.WriteLine(carro.Marca); // Saída: Toyota
  ```  
- **Uso com LINQ**:  
  ```csharp
  var novosCachorros = cachorros.Select(x => new { Idade = x.Idade, PrimeiraLetra = x.Nome[0] });
  ```

---

### 5. LINQ (Language Integrated Query)
- **Objetivo**: Realizar consultas em coleções de dados com sintaxe semelhante ao SQL.  
- **Operações Principais**:
  - **Filtro (`where`)**:
    ```csharp
    var numerosPares = from num in numeros where num % 2 == 0 select num;
    ```
  - **Ordenação (`orderby`)**:
    ```csharp
    var nomesOrdenados = from nome in nomes orderby nome.Length descending select nome;
    ```
  - **Agrupamento (`group by`)**:
    ```csharp
    var grupos = from num in numeros group num by num % 5 into g select new { Resto = g.Key, Numeros = g };
    ```
  - **Junção (`join`)**:
    ```csharp
    var produtosComCategoria = from p in produtos join c in categorias on p.IDCategoria equals c.ID select new { p.Nome, c.NomeCategoria };
    ```

---

### 6. Diferenças entre Métodos Chave
| Método         | Descrição                                      | Exemplo                          |
|----------------|-----------------------------------------------|----------------------------------|
| `FindAll`      | Filtra elementos com base em um predicado.    | `list.FindAll(x => x > 5)`       |
| `Select`       | Transforma cada elemento em uma nova forma.   | `list.Select(x => x * 2)`        |
| `OrderBy`      | Ordena elementos em ordem ascendente.         | `list.OrderBy(x => x.Nome)`      |

---

### 7. Conclusão
- **Expressões Lambda**: Simplificam a manipulação de coleções e delegates.  
- **Métodos de Extensão**: Permitem estender tipos existentes de forma flexível.  
- **LINQ**: Oferece uma abordagem declarativa para consultas, integrando funcionalidades similares ao SQL em C#.  
- **Tipos Anônimos**: Úteis para criar estruturas de dados temporárias sem definir classes explícitas.  

Esses recursos são fundamentais para desenvolver código mais expressivo, modular e eficiente em C#.
