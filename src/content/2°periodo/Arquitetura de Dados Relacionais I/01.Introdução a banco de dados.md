##  Introdução a bancos de dados
### **1. Introdução**

- **Dados vs. Informação**:
    
    - **Dados**: Valores brutos e isolados (ex.: idade, peso de um paciente).
        
    - **Informação**: Dados contextualizados e interpretados (ex.: diagnóstico médico).
        
- **Tipos de Dados**: Alfanuméricos, áudio, imagens, vídeos.
    
- **Bancos de Dados Tradicionais vs. Especiais**:
    
    - **Tradicionais**: Armazenam principalmente textos e números (ex.: transações bancárias).
        
    - **Especiais**: Lidam com multimídia, georreferenciamento, big data, etc.
        

### **2. Dados, Informação e Conhecimento**

- **Conhecimento**: Uso da informação para decisões (ex.: regras médicas aplicadas a dados de pacientes).
    
- **Qualidade da Informação**:
    
    - Requisitos: Precisão, consistência, atualidade, disponibilidade, unicidade.
        
    - Dimensões: Qualidade do dado, processo de manufatura, adequação ao receptor.
        
    - Exemplo: Informação deve ser acessível, precisa, completa e atual.
        

### **3. Sistema de Banco de Dados**

- **Definição**: Conjunto de dados inter-relacionados que refletem aspectos do mundo real.
    
- **Aplicações**:
    
    - Empresarial (vendas, RH), acadêmico (matrículas, artigos), navegação (GPS), redes sociais.
        
- **Componentes**:
    
    - **SGBD (Sistema Gerenciador)**: Controla criação, manipulação e segurança do BD.
        
    - **Metadados**: Estruturas que definem os dados (ex.: catálogo de campos).
        
    - **Programas de Aplicação**: Interface entre usuários e SGBD.
        
- **Características**:
    
    - **Abstração de Dados**: Usuários não precisam conhecer detalhes de armazenamento.
        
    - **Visões Múltiplas**: Dados virtuais personalizados para diferentes usuários.
        
    - **Transações Multiusuário**: Controle de concorrência e atomicidade (tudo ou nada).
        

### **4. Conclusão**

- Bancos de dados são essenciais no cotidiano (ex.: e-commerce, redes sociais).
    
- Vantagens: Facilidade de uso, segurança, compartilhamento eficiente de dados.
    
- Tecnologias emergentes (big data, IA) complementam, mas não substituem bancos tradicionais.

**Destaques**:

- A diferença entre **dados** (brutos) e **informação** (contextualizada) é central.
    
- SGBDs garantem **segurança**, **abstração** e **eficência** no manejo de dados.
    
- Aplicações variam desde sistemas simples (agenda) até complexos (Mercado Livre).
