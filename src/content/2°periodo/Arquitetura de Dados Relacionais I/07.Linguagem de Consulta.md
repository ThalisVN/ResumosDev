## Linguagem de Consulta

### 1. **Introdução à SQL**
- **SQL (Structured Query Language)**: linguagem declarativa de alto nível para manipulação e definição de dados em bancos relacionais.
- **Histórico**:
  - Desenvolvida pela IBM como **SEQUEL** (1974).
  - Padronizada pela ANSI e ISO em 1986 (SQL-86).
  - Versões posteriores: SQL-89, SQL-92, SQL:1999, SQL:2003, SQL:2006, SQL:2008, SQL:2011, SQL:2016.
- **Terminologia**:
  - Tabela (relação), Linha (tupla), Coluna (atributo).
- **Categorias da SQL**:
  - **DDL (Data Definition Language)**: Definição de estrutura.
  - **DML (Data Manipulation Language)**: Manipulação de dados.
  - **DCL (Data Control Language)**: Controle de acesso.
  - **DTL (Data Transaction Language)**: Controle de transações.

### 2. **Tipos de Dados em SQL**
- **Numéricos**: `INT`, `DECIMAL(n, d)`, `FLOAT(n)`.
- **Strings**: `CHAR(n)`, `VARCHAR(n)`.
- **Data/Hora**: `DATE`, `TIME`.
- **Booleanos**: `TRUE`, `FALSE`, `UNKNOWN`.

### 3. **Data Definition Language (DDL)**
- **Criar Banco**:  
  ```sql
  CREATE DATABASE BDAcademico;
  ```
- **Excluir Banco**:  
  ```sql
  DROP DATABASE BDAcademico;
  ```
- **Criar Tabela**:
  ```sql
  CREATE TABLE TBCurso (
      Cod_Curso INT PRIMARY KEY,
      Nome_Curso VARCHAR(50) NOT NULL
  );
  ```
- **Chave Estrangeira**:
  ```sql
  CREATE TABLE TBAluno (
      Mat_Aluno INT PRIMARY KEY,
      Nome_Aluno VARCHAR(50),
      Curso_Aluno INT,
      FOREIGN KEY (Curso_Aluno) REFERENCES TBCurso(Cod_Curso)
  );
  ```
- **Alterar Tabela**:
  ```sql
  ALTER TABLE TBAluno
  ADD Cidade_Aluno VARCHAR(30) DEFAULT 'Vila Velha',
  MODIFY Nome_Aluno VARCHAR(60),
  DROP COLUMN RG_Aluno;
  ```
- **Excluir Tabela**:
  ```sql
  DROP TABLE TBAluno;
  ```

### 4. **Data Manipulation Language (DML)**
- **Inserir Dados**:
  ```sql
  INSERT INTO TBAluno (Mat_Aluno, Nome_Aluno, Curso_Aluno, Cidade_Aluno)
  VALUES (1001, 'Teresa de Jesus', 1, 'Salvador');
  ```
- **Excluir Dados**:
  ```sql
  DELETE FROM TBAluno WHERE Curso_Aluno = 1;
  ```
- **Atualizar Dados**:
  ```sql
  UPDATE TBAluno
  SET Cidade_Aluno = 'Rio de Janeiro'
  WHERE Cidade_Aluno <> 'Belo Horizonte';
  ```
- **Consultar Dados**:
  ```sql
  SELECT Nome_Aluno, Cidade_Aluno
  FROM TBAluno
  WHERE Curso_Aluno = 1
  ORDER BY Nome_Aluno ASC;
  ```
- **Junção entre Tabelas**:
  ```sql
  SELECT A.Nome_Aluno, C.Nome_Curso
  FROM TBAluno A
  INNER JOIN TBCurso C ON A.Curso_Aluno = C.Cod_Curso;
  ```

### 5. **Data Transaction Language (DTL) e Data Control Language (DCL)**
- **Transações**:
  - `COMMIT`: Confirma alterações.
  - `ROLLBACK`: Desfaz alterações.
- **Controle de Acesso**:
  - `GRANT`: Concede permissões.
  - `REVOKE`: Revoga permissões.
### 6. **Conclusão**
- SQL é a linguagem padrão para SGBDs relacionais.
- Permite definição, manipulação, controle e segurança de dados.
- Comandos essenciais: `CREATE`, `ALTER`, `DROP`, `INSERT`, `UPDATE`, `DELETE`, `SELECT`.
- Suporta transações e controle de acesso granular.
