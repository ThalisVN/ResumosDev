# Administração de um Sistema Operacional

## 1. Conceitos Fundamentais

### 1.1 O que é Administração de Sistemas Operacionais?
A administração de sistemas operacionais é uma tarefa **multidisciplinar** que envolve gerenciar a interação entre o sistema operacional, o hardware, os aplicativos e os usuários finais.

| Área de Atuação | Descrição |
|-----------------|-----------|
| **Gerenciamento de contas** | Criação, modificação e remoção de usuários e grupos |
| **Controle de acesso** | Configuração de permissões e privilégios |
| **Manutenção de segurança** | Atualizações, patches e políticas de senha |
| **Monitoramento** | Performance, logs e resolução de problemas |

---

### 1.2 Usuários e Grupos
Cada sistema operacional permite que múltiplos usuários interajam de forma segura. Os usuários são organizados em **grupos** para facilitar o gerenciamento de acesso.

| Conceito | Descrição |
|----------|-----------|
| **Usuário** | Conta individual com permissões específicas |
| **Grupo** | Conjunto de usuários com privilégios compartilhados |
| **GID (Group ID)** | Número único que identifica cada grupo no sistema |
| **Privilégios** | Ações que um usuário/grupo pode realizar |

---

## 2. Gerenciamento de Usuários e Grupos

### 2.1 Comandos para Gerenciamento de Grupos

| Comando | Função | Exemplo |
|---------|--------|---------|
| **`addgroup`** | Criar novo grupo | `addgroup desenvolvedores` |
| **`delgroup`** | Remover grupo existente | `delgroup desenvolvedores` |
| **`cat /etc/group`** | Exibir todos os grupos | `cat /etc/group` |
| **`grep`** | Filtrar informações de grupo | `grep desenvolvedores /etc/group` |

**Estrutura do arquivo `/etc/group`:**
```
nome_do_grupo:x:GID:lista_de_usuários
```
- `x`: marcador para senha do grupo (armazenada em `/etc/gshadow`)

---

### 2.2 Comandos para Gerenciamento de Usuários

| Comando | Função | Características |
|---------|--------|-----------------|
| **`adduser`** | Criar usuário (amigável) | Guia o administrador com prompts interativos |
| **`useradd`** | Criar usuário (baixo nível) | Requer todas as informações como argumentos |
| **`passwd`** | Definir/alterar senha | `passwd fulano` |
| **`usermod`** | Modificar conta existente | Adicionar a grupos, alterar shell, etc. |
| **`whoami`** | Exibir usuário atual | Útil após usar `su` |
| **`groups`** | Exibir grupos do usuário | `groups fulano` |

**Exemplo de criação de usuário:**
```bash
useradd fulano
passwd fulano
```

---

### 2.3 Adicionar Usuário a Grupo

```bash
usermod -aG desenvolvedores fulano
```

| Opção | Significado |
|-------|-------------|
| `-a` | Append (adiciona sem remover de outros grupos) |
| `-G` | Group (especifica grupos suplementares) |

---

### 2.4 Arquivos de Senha e Segurança

| Arquivo | Conteúdo | Permissões |
|---------|----------|------------|
| **`/etc/passwd`** | Informações básicas dos usuários | Leitura ampla |
| **`/etc/shadow`** | Senhas criptografadas (hashes) | Restrito ao root |
| **`/etc/group`** | Informações dos grupos | Leitura ampla |
| **`/etc/gshadow`** | Senhas criptografadas dos grupos | Restrito ao root |

---

### 2.5 Hashing de Senhas

| Característica | Descrição |
|----------------|-----------|
| **Algoritmo** | Função de mão única |
| **Processo** | Senha → Hash → Armazenamento |
| **Verificação** | Senha fornecida → Hash → Comparação |
| **Segurança** | Hash não pode ser revertido para senha original |

## 3. Privilégios e Controle de Acesso

### 3.1 O Comando sudo

| Aspecto | Descrição |
|---------|-----------|
| **Significado** | Super User DO |
| **Função** | Executar comandos com privilégios de root |
| **Funcionamento** | Solicita senha do usuário, verifica autorização em `/etc/sudoers` |
| **UID** | Executa com UID 0 (root) devido ao bit setuid |

---

### 3.2 Bit setuid
- Programas com bit setuid executam com privilégios do **proprietário do arquivo**, não do usuário que executa
- `sudo` tem proprietário root e bit setuid ativado

---

### 3.3 Arquivo sudoers

| Característica | Descrição |
|----------------|-----------|
| **Localização** | `/etc/sudoers` |
| **Edição** | Apenas com `visudo` (verifica sintaxe e evita conflitos) |
| **Estrutura** | `usuário host=(usuário_alvo) comandos` |

---

### 3.4 Grupos com Privilégios sudo

| Distribuição | Grupo |
|--------------|-------|
| **Debian-based** (Ubuntu) | `sudo` |
| **Red Hat-based** | `wheel` |

**Adicionar usuário ao grupo sudo:**
```bash
sudo usermod -aG sudo fulano
```

## 4. Permissões de Arquivos e Diretórios

### 4.1 Atributos de Controle de Acesso

| Atributo | Descrição |
|----------|-----------|
| **Usuário dono** | Proprietário do arquivo/diretório |
| **Grupo** | Grupo associado ao arquivo/diretório |
| **Permissões** | Leitura (r), Escrita (w), Execução (x) |

---

### 4.2 Estrutura de Permissões (ls -l)

```
-rw-r--r-- 1 fulano grupo1 398 Jul 26 09:21 exemplo.txt
```

| Posição | Significado |
|---------|-------------|
| **Caractere 1** | Tipo: `-` (arquivo), `d` (diretório), `l` (link) |
| **Caracteres 2-4** | Permissões do **dono** (rwx) |
| **Caracteres 5-7** | Permissões do **grupo** (rwx) |
| **Caracteres 8-10** | Permissões de **outros** (rwx) |
| **Número** | Contagem de links |
| **Nome** | Usuário proprietário |
| **Grupo** | Grupo proprietário |
| **Tamanho** | Em bytes |
| **Data** | Última modificação |

---

### 4.3 Representação Octal de Permissões

| Permissão | Valor |
|-----------|-------|
| Leitura (r) | 4 |
| Escrita (w) | 2 |
| Execução (x) | 1 |

**Soma dos valores** determina o conjunto de permissões:

| Octal | Permissões | Significado |
|-------|------------|-------------|
| 7 | rwx | Leitura + Escrita + Execução |
| 6 | rw- | Leitura + Escrita |
| 5 | r-x | Leitura + Execução |
| 4 | r-- | Apenas Leitura |
| 0 | --- | Nenhuma |

---

### 4.4 Comando chmod

| Sintaxe | Função |
|---------|--------|
| `chmod 640 arquivo` | Dono: rw- (6), Grupo: r-- (4), Outros: --- (0) |
| `chmod 700 *.txt` | Permissão total para dono em todos os .txt |
| `chmod -R 700 diretorio` | Recursivo: aplica a todo conteúdo do diretório |

---

### 4.5 Comando chown

| Sintaxe | Função |
|---------|--------|
| `chown fulano arquivo` | Altera proprietário |
| `chown fulano:grupo1 arquivo` | Altera proprietário e grupo |
| `chown fulano:grupo1 *.txt` | Aplica a múltiplos arquivos |
| `chown -h link` | Altera proprietário do link simbólico (não do alvo) |

## 5. Práticas Recomendadas

### 5.1 Gerenciamento de Senhas

| Prática | Descrição | Implementação |
|---------|-----------|---------------|
| **Senhas fortes** | Maiúsculas, minúsculas, números, caracteres especiais | PAM (Pluggable Authentication Modules) |
| **Expiração** | Alteração periódica obrigatória | `chage` |
| **Armazenamento seguro** | Hashes no `/etc/shadow` | Algoritmos criptográficos |
| **Menor privilégio** | Usuários têm apenas acesso necessário | Grupos e permissões |

---

### 5.2 RBAC (Controle de Acesso Baseado em Funções)

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Permissões atribuídas por função, não por indivíduo |
| **Implementação básica** | Grupos de usuários no Linux |
| **Implementação avançada** | SELinux, AppArmor |
| **Benefícios** | Simplifica gerenciamento, aumenta segurança, facilita auditoria |

---

### 5.3 Automação de Tarefas Administrativas

| Ferramenta | Função |
|------------|--------|
| **Scripts Shell** | Sequências de comandos automatizados |
| **cron / crontab** | Agendamento de tarefas periódicas |
| **Ansible** | Automação de configuração e gerenciamento |
| **Puppet / Chef** | Gerenciamento de configuração em larga escala |

## 6. Solução de Problemas Comuns

| Problema | Ferramentas de Diagnóstico | Ações |
|----------|---------------------------|-------|
| **Permissões** | `ls -l` | `chmod`, `chown` |
| **Autenticação** | `/etc/shadow`, `passwd` | Verificar status da conta, redefinir senha |
| **Performance** | `top`, `vmstat`, `iostat`, `free` | Identificar gargalos (CPU, memória, I/O) |
| **Rede** | `ping`, `netstat`, `traceroute`, `ss` | Testar conectividade, verificar portas |

## 7. Cenários Práticos

### 7.1 Nova Equipe de Desenvolvedores

**Necessidade**: Criar usuários individuais e grupo compartilhado

```bash
# Criar grupo
addgroup desenvolvedores

# Criar usuários e adicionar ao grupo
useradd -m dev1
passwd dev1
usermod -aG desenvolvedores dev1

# Repetir para dev2, dev3...
```

---

### 7.2 Servidor Web com Múltiplos Sites

**Necessidade**: Isolar acesso entre desenvolvedores

```bash
# Criar diretórios por site
mkdir /var/www/site1 /var/www/site2

# Definir proprietários
chown dev1:desenvolvedores /var/www/site1
chown dev2:desenvolvedores /var/www/site2

# Configurar permissões
chmod 750 /var/www/site1  # Dono: rwx, Grupo: r-x, Outros: ---
```

---

### 7.3 Backup Automatizado com cron

**Necessidade**: Backup diário de diretórios importantes

```bash
# Editar crontab
crontab -e

# Adicionar linha (backup todo dia às 2h)
0 2 * * * /home/admin/backup.sh
```

## 9. Conclusão

A administração eficaz de sistemas operacionais requer domínio de:

- **Gerenciamento de usuários e grupos**: Criação, modificação e remoção com comandos apropriados
- **Controle de privilégios**: Uso seguro do `sudo` e configuração adequada do `/etc/sudoers`
- **Permissões de arquivos**: Compreensão e aplicação de `chmod` e `chown`
- **Segurança**: Políticas de senha, RBAC e princípio do menor privilégio
- **Automação**: Scripts, cron e ferramentas de configuração
- **Diagnóstico**: Identificação e resolução de problemas comuns

O administrador de sistemas atua como guardião da **eficiência, segurança e funcionalidade** do ambiente computacional.
