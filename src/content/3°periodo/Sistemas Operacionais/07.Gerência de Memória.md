# Gerência de Memória

## 1. Conceitos Fundamentais

### 1.1 Evolução da Gerência de Memória

| Época | Característica |
|-------|----------------|
| **Primórdios UNIX** | Métodos simples de alocação contígua; hardware limitado |
| **Evolução** | Paginação e segmentação para maior flexibilidade |
| **Atual** | Memória virtual, cache multinível, otimizações avançadas |

---

### 1.2 Importância da Gerência de Memória

| Impacto | Descrição |
|---------|-----------|
| **Velocidade** | Acesso eficiente aos dados |
| **Responsividade** | Sistema responde rapidamente |
| **Capacidade** | Execução de aplicações exigentes |
| **Multitarefa** | Suporte a múltiplos usuários e processos |

---

## 2. Memória Física e Memória Virtual

### 2.1 Memória Física (RAM)

| Tipo | Características | Aplicação |
|------|-----------------|-----------|
| **SRAM** | Mais rápida; não requer refresh; menor densidade; cara | Cache de CPU |
| **DRAM** | Mais lenta; requer refresh periódico; maior densidade; econômica | Memória principal |

---

### 2.2 Memória Virtual

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Técnica que utiliza disco rígido para expandir artificialmente a memória |
| **Objetivo** | Criar ilusão de memória abundante |
| **Mecanismo** | Paginação - memória dividida em blocos de tamanho fixo |

---

### 2.3 Buffer vs. Cache

| Conceito | Função | Localização |
|----------|--------|-------------|
| **Buffer** | Armazenamento temporário para transferência entre velocidades diferentes | Entre disco e RAM |
| **Cache** | Armazena cópias de dados frequentemente acessados | Próximo à CPU (multinível) |

**Níveis de Cache:**
- L1: Mais rápido, menor, dentro do núcleo
- L2: Intermediário
- L3: Compartilhado entre núcleos

---

### 2.4 Palavra de Memória

| Arquitetura | Palavra | Limite de Endereçamento |
|-------------|---------|-------------------------|
| **32 bits** | 32 bits (4 bytes) | 4 GB (2³² endereços) |
| **64 bits** | 64 bits (8 bytes) | 16 EB (2⁶⁴ endereços) |

---

## 3. Swap e Memória Virtual

### 3.1 Conceito de Swap

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Extensão da memória física em disco |
| **Função** | Mover páginas inativas da RAM para o disco |
| **Benefício** | Libera RAM para dados ativos |
| **Risco** | Acesso a disco é mais lento que RAM |

---

### 3.2 Algoritmos de Substituição de Páginas

| Algoritmo | Descrição |
|-----------|-----------|
| **LRU** | Least Recently Used - substitui página menos recentemente usada |
| **FIFO** | First In First Out - substitui página mais antiga |
| **LFU** | Least Frequently Used - substitui página menos frequentemente usada |

---

### 3.3 Comando `free`

| Informação | Descrição |
|------------|-----------|
| **Total** | Memória total disponível |
| **Used** | Memória em uso |
| **Free** | Memória livre |
| **Shared** | Memória compartilhada |
| **Buff/Cache** | Memória usada para buffers e cache |
| **Available** | Memória disponível para novos processos |
| **Swap Total/Used/Free** | Estatísticas do espaço de swap |

---

## 4. Swappiness

### 4.1 Conceito

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Parâmetro do kernel Linux que influencia tendência de usar swap |
| **Range** | 0 a 100 |
| **Valor baixo** | Kernel evita swap, mantém processos em RAM |
| **Valor alto** | Kernel usa swap mais agressivamente |

---

### 4.2 Configuração

| Método | Comando/Arquivo |
|--------|-----------------|
| **Temporário** | `echo 10 > /proc/sys/vm/swappiness` |
| **Permanente** | Adicionar `vm.swappiness=10` em `/etc/sysctl.conf` |

---

### 4.3 Comandos de Swap

| Comando | Função |
|---------|--------|
| **`swapon`** | Ativa área de swap |
| **`swapoff`** | Desativa área de swap |

---

### 4.4 Recomendações de Tamanho de Swap

| Quantidade de RAM | Recomendação Tradicional | Recomendação Moderna |
|--------------------|--------------------------|----------------------|
| Até 2 GB | 2x RAM | 1-2x RAM |
| 2-8 GB | 1x RAM | 0.5-1x RAM |
| > 8 GB | 0.5x RAM | 4-8 GB (hibernação) |

---

## 5. Paginação e Tabelas de Página

### 5.1 Conceito de Paginação

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Divisão da memória física em blocos de tamanho fixo (páginas) |
| **Vantagem** | Elimina necessidade de alocação contígua |
| **Benefício** | Reduz fragmentação externa |

---

### 5.2 Tabela de Páginas

| Aspecto | Descrição |
|---------|-----------|
| **Função** | Mapeia endereços virtuais para endereços físicos |
| **Localização** | Memória principal |
| **Conteúdo** | Registro de todas as páginas do processo e suas localizações |

---

### 5.3 Page Fault

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Ocorre quando página necessária não está na memória física |
| **Ação** | SO traz página do swap de volta para RAM |
| **Transparência** | Invisível para o processo |
| **Risco** | Frequência excessiva causa thrashing |

---

### 5.4 PTBR (Page-Table Base Register)

| Aspecto | Descrição |
|---------|-----------|
| **Função** | Registro da MMU que aponta para tabela de páginas do processo atual |
| **Atualização** | A cada troca de contexto |
| **Importância** | Permite tradução rápida de endereços |

---

## 6. Segmentação e Tabelas de Segmentação

### 6.1 Conceito de Segmentação

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Divisão do programa em unidades lógicas (segmentos) |
| **Segmentos típicos** | Código, dados, pilha (stack), heap |
| **Vantagem** | Reflete estrutura lógica do programa |
| **Proteção** | Cada segmento com permissões específicas |

---

### 6.2 Heap vs. Stack

| Aspecto | Stack (Pilha) | Heap |
|---------|---------------|------|
| **Alocação** | Automática (compilador) | Manual (programador) ou GC |
| **Tamanho** | Conhecido em tempo de compilação | Dinâmico |
| **Uso** | Variáveis locais, chamadas de função | Objetos dinâmicos |
| **Gerenciamento** | LIFO automático | Alocação/liberação explícita |

---

### 6.3 Tabela de Segmentação

| Aspecto | Descrição |
|---------|-----------|
| **Função** | Armazena endereço base e tamanho de cada segmento |
| **Mecanismo** | MMU consulta para traduzir endereço virtual em físico |

---

### 6.4 STBR (Segment-Table Base Register)

| Aspecto | Descrição |
|---------|-----------|
| **Função** | Armazena endereço da tabela de segmentação na memória |
| **Atualização** | A cada troca de contexto |
| **Importância** | Permite transição rápida entre espaços de endereçamento |

---

### 6.5 Comparação: Paginação vs. Segmentação

| Critério | Paginação | Segmentação |
|----------|-----------|-------------|
| **Unidade** | Páginas (tamanho fixo) | Segmentos (tamanho variável) |
| **Fragmentação** | Interna | Externa |
| **Visibilidade ao programador** | Transparente | Visível |
| **Estrutura** | Não reflete lógica do programa | Reflete lógica do programa |
| **Proteção** | Por página | Por segmento |

---

## 7. Memória Virtual e Cache

### 7.1 Throughput

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Taxa de processamento de dados do sistema ao longo do tempo |
| **Influência do cache** | Mais cache hits = maior throughput |
| **Influência da memória virtual** | Menos page faults = maior throughput |

---

### 7.2 Algoritmos de Substituição de Cache

| Algoritmo | Descrição |
|-----------|-----------|
| **LRU** | Least Recently Used |
| **FIFO** | First In First Out |
| **LFU** | Least Frequently Used |

---

### 7.3 Tipos de Associação de Cache

| Tipo | Característica | Vantagem | Desvantagem |
|------|----------------|----------|-------------|
| **Mapeamento Direto** | Cada bloco tem posição fixa | Simples, rápido | Mais conflitos |
| **Totalmente Associativo** | Bloco pode estar em qualquer posição | Flexível, menos conflitos | Caro, complexo |
| **Associativo por Conjunto** | Compromisso entre os dois | Bom equilíbrio | Complexidade média |

---

### 7.4 Técnicas de Otimização

| Técnica | Descrição |
|---------|-----------|
| **Prefetching** | Busca antecipada de dados prováveis de uso |
| **Dimensionamento** | Tamanho adequado do cache |
| **Write-back/Write-through** | Políticas de escrita |

---

## 8. Endereçamento e Fragmentação

### 8.1 Tipos de Endereços

| Tipo | Descrição |
|------|-----------|
| **Endereço Lógico (Virtual)** | Referência vista pelo programa/usuário |
| **Endereço Físico** | Localização real na RAM |

**Tradução**: MMU converte endereços lógicos em físicos

---

### 8.2 Tipos de Fragmentação

| Tipo | Descrição | Solução |
|------|-----------|---------|
| **Externa** | Espaço livre total suficiente, mas não contíguo | Paginação, compactação |
| **Interna** | Bloco alocado maior que o necessário | Segmentação |

---

### 8.3 Comparação: Fragmentação Externa vs. Interna

| Critério | Externa | Interna |
|----------|---------|---------|
| **Causa** | Alocação/liberação de blocos variáveis | Tamanho fixo de página |
| **Memória desperdiçada** | Entre blocos alocados | Dentro do bloco alocado |
| **Solução principal** | Paginação | Segmentação |

---

## 9. Swapping de Processos

### 9.1 Conceito

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Transferência de processos inteiros entre RAM e swap |
| **Objetivo** | Liberar RAM para processos ativos |
| **Diferença da Paginação** | Swap move processos inteiros; paginação move páginas |

---

### 9.2 Thrashing

| Aspecto | Descrição |
|---------|-----------|
| **Definição** | Estado em que sistema gasta mais tempo trocando páginas que executando |
| **Causa** | Memória física insuficiente para conjunto de trabalho |
| **Sintoma** | Alto I/O de disco, CPU ociosa |
| **Solução** | Aumentar RAM, reduzir processos, ajustar swappiness |

---

### 9.3 Comando `stress`

| Parâmetro | Função |
|-----------|--------|
| `--vm N` | Número de processos de trabalho |
| `--vm-bytes M` | Memória alocada por processo |

**Exemplo:**
```bash
stress --vm 4 --vm-bytes 512M
```

## 11. Conclusão

A gerência de memória em sistemas operacionais modernos é uma combinação sofisticada de técnicas:

- **Memória física vs. virtual**: RAM limitada expandida via disco
- **Cache e buffer**: Redução de latência entre CPU e memória
- **Paginação**: Alocação flexível em blocos fixos
- **Segmentação**: Organização lógica com proteção por segmento
- **Swap**: Extensão da RAM em disco
- **Swappiness**: Controle fino do comportamento de swapping
- **Tabelas de página/segmentação**: Mapeamento virtual→físico
- **PTBR/STBR**: Registradores para tradução rápida
- **Fragmentação**: Desafios e soluções (paginação/segmentação)

O domínio desses conceitos permite otimizar o desempenho, diagnosticar problemas e configurar adequadamente sistemas para diferentes cargas de trabalho.
