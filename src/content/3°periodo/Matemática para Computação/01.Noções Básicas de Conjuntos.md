# Noções Básicas de Conjuntos

## 1. Introdução
- A matemática é a base da computação.
- Alan Turing (pai da ciência da computação) criou a **Máquina de Turing**, um modelo lógico que funciona como uma função matemática: recebe entradas, processa instruções (algoritmos) e gera saídas.
- A **Teoria dos Conjuntos** é um dos conceitos mais fundamentais para a computação.

---

## 2. Notação de Teoria dos Conjuntos
- **Conjunto**: coleção de objetos com características comuns.
- **Elemento**: cada objeto que pertence a um conjunto.
- **Representação**: letras maiúsculas e elementos entre chaves `{}`.
  - Ex: `A = {Vermelho, Azul, Amarelo}`
- **Pertinência**:
  - `∈` : pertence
  - `∉` : não pertence
- **Conjuntos Numéricos**:
  - `N` (naturais), `Z` (inteiros), `Q` (racionais), `I` (irracionais), `R` (reais), `C` (complexos)
- **Notações especiais**:
  - `*` : exclusão do zero (ex: `Z*`)
  - `+` : não negativos (ex: `Q+`)
  - `-` : não positivos (ex: `R-`)
- **Igualdade de conjuntos**: dois conjuntos são iguais se possuem os mesmos elementos.
- **Propriedades da igualdade**: reflexiva, simétrica e transitiva.
- **Representação por propriedade**:
  - Ex: `P = {x | x é par}`
- **Conjuntos especiais**:
  - **Unitário**: apenas um elemento
  - **Vazio**: `{ }` ou `Ø`

---

## 3. Subconjuntos e Conjunto das Partes
- **Subconjunto (`⊂`)**: todos os elementos de A também estão em B.
  - Ex: `A = {2,5}`, `B = {2,5,7}` → `A ⊂ B`
- **Conjunto vazio** é subconjunto de qualquer conjunto.
- **Família de conjuntos**: conjunto cujos elementos também são conjuntos.
- **Diagrama de Euler-Venn**: representação gráfica das relações entre conjuntos.
- **Conjunto das Partes (`P(A)`)**: conjunto de todos os subconjuntos possíveis de A.
  - Ex: `A = {1,2,3}` → `P(A) = {Ø, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}}`
  - Número de elementos: `2^n`, onde `n` é o número de elementos de A.
- **Conjunto Universo (`U`)**: conjunto que contém todos os elementos considerados em um contexto.

---

## 4. Operações Binárias e Unárias
- **Operação binária**: combina dois elementos de um conjunto e gera um único resultado.
  - Ex: soma, subtração, multiplicação em `Z`
  - A ordem importa (par ordenado)
- **Par ordenado**: `(x, y)` é diferente de `(y, x)`
- **Operação unária**: opera sobre um único elemento.
  - Ex: `√4`, `|−7|`, `cos(60°)`, `3²`, `6!`

---

## 5. Conclusão
- A Teoria dos Conjuntos é essencial para a computação.
- Compreender conjuntos, subconjuntos, operações e notações é fundamental para resolver problemas e estruturar algoritmos.
