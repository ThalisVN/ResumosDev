# Definições e Propriedades das Relações Algébricas

## 1. Introdução
- Relações estão presentes em diversos contextos: familiar, profissional, matemático.
- Na matemática, relações entre conjuntos são fundamentais para definir **funções**, modelar sistemas, prever fenômenos e estruturar bancos de dados.

---

## 2. Relação Binária

- **Relação binária** entre dois conjuntos A e B é um **subconjunto do produto cartesiano**  $A \times B$.
- Notação: $x \rho y$ significa que $(x, y) \in \rho$.
- Pode ser definida por **propriedade característica** em vez de listagem.

**Exemplo:**
- $A = \{1,2\} ,  B = \{1,2,3\}$
- $\rho = \{(x,y) \in A \times B \mid x + y \text{ é ímpar}\}$
- Resultado: $\rho = \{(1,2), (2,1), (2,3)\}$

#### Relação n-ária
- Generalização para n conjuntos: $R \subseteq A_1 \times A_2 \times \dots \times A_n$
- \( n=1 \): relação unária
- \( n=2 \): relação binária
- \( n=3 \): relação ternária

### 3. Representações Gráficas

- **Diagrama de setas**: elementos de A ligados a elementos de B por setas, se $(x,y) \in R$.
- **Plano cartesiano**: gráfico da relação (ex:  $y = x^2 + 2x + 20$).

#### Tipos de relação (quanto à correspondência):
- **Um-pra-um (injetiva)**: cada elemento de A e B aparece uma única vez.
- **Um-para-vários**: um elemento de A se relaciona com vários de B.
- **Vários-para-um**: vários elementos de A se relacionam com um de B.
- **Vários-para-vários**: ocorrem múltiplas conexões em ambos os lados.

### 4. Propriedades das Relações Binárias

Seja \( R \) uma relação binária em um conjunto \( A \):

| Propriedade        | Definição                                                | Exemplo                           |
| ------------------ | -------------------------------------------------------- | --------------------------------- |
| **Reflexiva**      | $\forall x \in A, (x,x) \in R$                           | $x \leq x$                        |
| **Simétrica**      | Se $(x,y) \in R, então   (y,x) \in R$                    | $x = y$                           |
| **Antissimétrica** | Se $(x,y) \in R ) e ( (y,x) \in R ), então ( x = y$)     | $x \leq y$                        |
| **Transitiva**     | Se $(x,y) \in R ) e ( (y,z) \in R ), então  (x,z) \in R$ | $(x < y ) e ( y < z ) ⇒ ( x < z)$ |

**Exemplo:**  $R = \{(x,y) \in \mathbb{R}^2 \mid x < y\}$
- Não é reflexiva (  $x < x$ é falso)
- Não é simétrica ( $x < y$ não implica $y < x$)
- É antissimétrica? Para  $(x < y ) e ( y < x)$ simultaneamente, só se \( x = y \) (contradição, então a condição nunca é satisfeita, o que torna a propriedade **vacuamente verdadeira**)
- É transitiva $( x < y ) \ e  \ ( y < z ) ⇒ ( x < z )$ 

---

### 5. Ordenação Parcial (Poset)

- Uma relação é uma **ordenação parcial** se for **reflexiva, antissimétrica e transitiva**.
- Exemplo clássico: $( x \leq y )$ ou "x divide y" em $( \mathbb{N} )$.
- Notação: $(S, \leq)$ é um **conjunto parcialmente ordenado** (poset).
- **Predecessor / sucessor**: se $( x < y )$, $( x )$ é predecessor de $y$, $y$ é sucessor de $x$.
- **Predecessor imediato**: não existe $z$  tal que $( x < z < y )$.

### 6. Relações e Banco de Dados

- **Modelo Entidade-Relacionamento (ER)**: entidades (ex: professor, disciplina) e seus relacionamentos.
- **Modelo relacional**: dados organizados em **tabelas**.
  - Cada linha é uma **tupla**.
  - Cada coluna é um **atributo**.
- **Chave primária**: atributo que identifica unicamente cada tupla.
- **Chave estrangeira**: liga uma tabela a outra.

**Operações com relações (álgebra relacional):**
- **Select (σ)**: seleciona linhas que atendem a uma condição.
  - Ex: $( \sigma_{\text{carga horária} = 20}(\text{Professor-Ministra})$ \)
- **Project $(\pi)$**: seleciona colunas específicas.
  - Ex: $( \pi_{\text{carga horária, curso}}(\text{Professor})$ )

Essas operações geram **novas tabelas (relações)** a partir das existentes.

---

### 7. Conclusão
- Relações binárias e n-árias são fundamentais na matemática e na computação.
- Diagramas de setas e propriedades (reflexiva, simétrica, antissimétrica, transitiva) ajudam a classificar relações.
- Ordenações parciais (posets) organizam elementos hierarquicamente.
- Bancos de dados relacionais são aplicações diretas da teoria de relações, com operações como select e project.
