# Operações com Conjuntos

## 1. Introdução
- Problemas envolvendo grupos de elementos (como pesquisa de sistemas operacionais) podem ser resolvidos com operações entre conjuntos.
- **Diagrama de Euler-Venn**: ferramenta gráfica para visualizar relações entre conjuntos. Criado por John Venn, com referências a Leonhard Euler.

---

## 2. Operações com Conjuntos

#### União (∪)
- Elementos que pertencem a **A ou B**.
- Definição:  A∪B={x∣x∈A ou x∈B}

#### Interseção (∩)
- Elementos que pertencem a **A e B** simultaneamente.
- Definição: A∩B={x∣x∈A e x∈B}
- Se A∩B=∅, os conjuntos são **disjuntos**.

#### Diferença (−)
- Elementos que pertencem a **A, mas não a B**.
- Definição: \(A−B={x∣x∈A e x∈/B}

#### Complemento (C)
- Elementos do conjunto universo **que não pertencem a A**.
- Definição: AC={x∈S∣x∈/A}

#### Produto Cartesiano (×)
- Conjunto de todos os **pares ordenados** (x, y) com x ∈ A e y ∈ B.
- Definição: A×B={(x,y)∣x∈A e y∈B}
- Importante: a ordem importa! A×B $\neq$ B×A
- Notação: A×A=A²

---

## 3. Propriedades das Operações

| Propriedade  | União               | Interseção          |
| ------------ | ------------------- | ------------------- |
| Comutativa   | A∪B=B∪A             | A∩B=B∩A             |
| Associativa  | (A∪B)∪C=A∪(B∪C)     | A∩B)∩C=A∩(B∩C)      |
| Distributiva | A∪(B∩C)=(A∪B)∩(A∪C) | A∩(B∪C)=(A∩B)∪(A∩C) |
| Identidade   | A∪∅=A               | A∩S=A               |
| Complemento  | A∪AC=S              | A∩AC=∅              |

#### Leis de De Morgan
- $(A \cup B)^c = A^c \cap B^c$
- \($A \cap B)^C = A^C \cup B^C$

---

## 4. Conclusão
- As operações com conjuntos (união, interseção, diferença, complemento, produto cartesiano) são fundamentais para resolver problemas com grupos de elementos.
- O Diagrama de Euler-Venn auxilia na visualização.
- As propriedades (comutativa, associativa, distributiva, identidade, complemento e Leis de De Morgan) são ferramentas importantes para simplificação e resolução de problemas.
