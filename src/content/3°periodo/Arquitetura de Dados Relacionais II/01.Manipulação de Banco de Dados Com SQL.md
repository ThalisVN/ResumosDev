# Manipulação de banco de dados com SQL
## Introdução à SQL
- **Definição**: Linguagem declarativa de alto nível para bancos de dados relacionais
- **Origem**: Desenvolvida pela IBM como SEQUEL (anos 70)
- **Padronização**: ANSI/ISO a partir de 1986 (SQL-86 → SQL:2016)
- **Vantagens**: Sintaxe simples, independente do SGBD, múltiplas visões dos dados

## Sublinguagens da SQL

| Categoria                            | Comandos principais            | Função                     |
| ------------------------------------ | ------------------------------ | -------------------------- |
| **DDL** (Data Definition Language)   | CREATE, DROP, ALTER            | Definir estrutura do banco |
| **DML** (Data Manipulation Language) | INSERT, DELETE, UPDATE, SELECT | Manipular dados            |
| **DCL** (Data Control Language)      | GRANT, REVOKE                  | Controlar permissões       |
| **DTL** (Data Transaction Language)  | COMMIT, ROLLBACK               | Gerenciar transações       |

## 3. Tipos de Dados
- **Numéricos**: INT, SMALLINT, NUMERIC(p,d), FLOAT(n)
- **Strings**: CHAR(n), VARCHAR(n), CLOB(n)
- **Data/hora**: DATE (DD-MM-AAAA), TIME (HH:MM:SS)
- **Booleanos**: TRUE, FALSE, UNKNOWN

## 4. DDL – Comandos Principais

### CREATE
- **CREATE SCHEMA** – criar esquema
- **CREATE TABLE** – criar tabela com atributos e restrições
- **CREATE INDEX** – criar índices (performance)

**Restrições**: NOT NULL, DEFAULT, CHECK, AUTO_INCREMENT, PRIMARY KEY, UNIQUE, FOREIGN KEY (com ON DELETE/ON UPDATE: NO ACTION, CASCADE, SET NULL, SET DEFAULT)

### DROP
- Remove elementos: `DROP TABLE TBAluno;` ou `DROP SCHEMA BDAcademico;`

### ALTER
- Altera estrutura: ADD COLUMN, DROP COLUMN, MODIFY COLUMN

## 5. DML – Comandos Principais

### INSERT INTO
- Incluir dados: `INSERT INTO Tabela (colunas) VALUES (valores);`

### DELETE FROM
- Excluir dados (com WHERE para filtrar)

### UPDATE
- Atualizar dados: `UPDATE tabela SET coluna=valor WHERE condição;`

### SELECT
- Consultar dados: `SELECT colunas FROM tabela WHERE condição;`
- Cláusulas: **WHERE** (filtro), **GROUP BY** (agrupamento), **ORDER BY** (ordenação ASC/DESC)
- Operadores: relacionais, lógicos, **LIKE** (curinga %), **IS NULL**
- Funções agregadas: SUM, AVG, MIN, MAX, COUNT

## 6. DCL – Permissões
- **GRANT** – conceder privilégios (SELECT, UPDATE, INSERT, DELETE)
- **REVOKE** – remover privilégios

## 7. Transações (DTL)
- **BEGIN** – iniciar transação
- **COMMIT** – confirmar alterações
- **ROLLBACK** – desfazer alterações

## 8. Conclusão
A SQL é uma linguagem padronizada, fácil de usar e essencial para gerenciar bancos de dados relacionais, permitindo definir estruturas, manipular dados, controlar acessos e gerenciar transações.
