# Listas encadeadas

## **1. Formas de Armazenamento em Listas**
- **Lista**: Sequência de elementos de um mesmo tipo (primitivo ou TAD), sem espaços vazios.
- **Classificação**:
  - **Estática**: Tamanho fixo, alocada em tempo de compilação (ex: array).
  - **Dinâmica**: Tamanho variável, alocada em tempo de execução (ex: lista encadeada).

---
## **2. Lista Estática**
- **Características**:
  - Tamanho fixo, definido na criação.
  - Alocação sequencial na memória.
  - Acesso direto por índice.
- **Vantagens**:
  - Acesso rápido (O(1)) por índice.
  - Tempo de acesso constante.
- **Desvantagens**:
  - Tamanho imutável.
  - Custo alto para inserção/exclusão no meio (deslocamento de elementos).
  - Pode desperdiçar memória (espaço não utilizado).

---

## **3. Lista Dinâmica (Encadeada)**
- **Características**:
  - Tamanho variável, alocado dinamicamente.
  - Elementos armazenados em **nós**, cada um contendo:
    - **Dado** (valor do elemento).
    - **Ponteiro** para o próximo nó (encadeamento simples) ou para anterior e próximo (encadeamento duplo).
- **Vantagens**:
  - Cresce/reduz conforme necessário.
  - Inserção/exclusão no meio são eficientes (apenas ajuste de ponteiros).
  - Uso eficiente de memória (aloca apenas o necessário).
- **Desvantagens**:
  - Acesso sequencial (busca lenta, O(n)).
  - Tempo de busca aumenta com o tamanho.
  - Requer gerenciamento manual de memória (risco de vazamento).

---

## **4. Tipos de Encadeamento**
- **Encadeamento Simples**:
  - Cada nó aponta apenas para o próximo.
  - Último nó aponta para `NULL`.
  - Percursos apenas em uma direção (frente).
- **Encadeamento Duplo**:
  - Cada nó aponta para o anterior e o próximo.
  - Permite percurso nos dois sentidos.
  - Mais flexível, mas usa mais memória (dois ponteiros por nó).

---

## **5. Implementação de Lista Simplesmente Encadeada (C)**
- **Estrutura de um nó**:
  ```c
  typedef struct Nodo {
      Aluno dado;          // Dados do elemento
      struct Nodo *prox;   // Ponteiro para o próximo nó
  } nodo;
  ```
- **Operações básicas**:
  - **Inserção no início**: Ajusta ponteiros do novo nó e da cabeça.
  - **Inserção no final**: Percorre até o último nó e ajusta ponteiro.
  - **Exclusão**: Ajusta ponteiros do nó anterior e libera memória (`free`).
  - **Percorrer/Imprimir**: Itera enquanto `prox != NULL`.
  - **Liberar memória**: Percorre a lista liberando cada nó.

---

## **6. Comparação entre Lista Estática e Encadeada**

| Critério              | Lista Estática (Array)             | Lista Encadeada                   |
| --------------------- | ---------------------------------- | --------------------------------- |
| **Tamanho**           | Fixo, pré-definido                 | Variável, limitado pela memória   |
| **Acesso por índice** | O(1) – rápido                      | O(n) – sequencial                 |
| **Inserção no meio**  | O(n) – desloca elementos           | O(1) – ajusta ponteiros           |
| **Inserção no final** | O(1) (se houver espaço)            | O(n) – percorre até o fim         |
| **Exclusão no meio**  | O(n) – desloca elementos           | O(1) – ajusta ponteiros           |
| **Uso de memória**    | Pode desperdiçar                   | Eficiente, aloca sob demanda      |
| **Indicação de uso**  | Listas pequenas, poucas alterações | Listas grandes, muitas alterações |

---

## **7. Conclusão**
- **Listas estáticas** são ideais quando o **tamanho é conhecido** e **acesso rápido por índice** é prioritário.
- **Listas encadeadas** são melhores quando o **tamanho varia muito** e **inserções/exclusões frequentes** ocorrem no meio da lista.
- A escolha depende dos **requisitos de desempenho**, **tamanho dos dados** e **frequência de modificações**.
