# Métodos de pesquisa em listas: sequencial, binária e tabelas hash

### **1. Busca Sequencial**

- **Funcionamento**: Percorre os elementos de uma lista ou vetor **um por um**, do início ao fim, até encontrar a chave desejada ou chegar ao final.
    
- **Complexidade**:
    
    - **Melhor caso**: O(1) (elemento na primeira posição)
        
    - **Pior caso**: O(N) (elemento não existe ou está no final)
        
- **Aplicação**: Indicada para **conjuntos pequenos** (até ~100 elementos).
    
- **Implementação simples** em Python.
    

---

### **2. Busca Binária**

- **Funcionamento**: Exige que os dados estejam **ordenados**. A cada iteração, o vetor é **dividido ao meio**, descartando a metade irrelevante.
    
- **Complexidade**:
    
    - **Melhor caso**: O(1)
        
    - **Pior caso**: O(log₂ N)
        
- **Aplicação**: Ideal para **conjuntos médios e grandes** (a partir de ~100 elementos).
    
- **Implementação** utiliza o paradigma **divisão e conquista**.
    

---

### **3. Tabelas Hash**

- **Funcionamento**: Mapeia **chaves** para **valores** usando uma **função hash**, que calcula um índice de armazenamento.
    
- **Colisões**: Ocorrem quando duas chaves geram o mesmo índice. Podem ser resolvidas com **listas encadeadas**.
    
- **Complexidade**:
    
    - **Caso médio**: O(1) para buscas
        
    - **Pior caso**: O(n) se houver muitas colisões
        
- **Aplicação**: Usada em **dicionários, sistemas de DNS, DHCP**, entre outros.
    
- **Vantagem**: Alta velocidade de busca.
    
- **Desvantagem**: Depende da qualidade da função hash.
    

---

### **4. Aplicações Práticas (C)**

- **Busca sequencial**: Exemplo de sistema universitário com menos de 100 alunos.
    
- **Busca binária**: Sistema em produção com muitos dados, exigindo desempenho.
    
- **Tabelas hash**: Gerenciamento de vagas de estacionamento com identificadores numéricos.
    

---

### **5. Conclusão**

Cada método tem seu contexto ideal:

- **Poucos dados** → Busca sequencial.
    
- **Dados ordenados e muitos elementos** → Busca binária.
    
- **Necessidade de acesso muito rápido** → Tabelas hash (com boa função hash).
