## Tipos abstratos de dados
### **1. O que é um TAD?**

Um **Tipo Abstrato de Dados (TAD)** é um modelo que define um conjunto de dados e as operações que podem ser realizadas sobre eles, **sem expor os detalhes de implementação**. O foco está no **comportamento** (o que faz) e não na representação interna (como faz).

- **Separação entre definição e implementação**: O TAD separa a interface (o que o usuário vê) da implementação (como é feito internamente).
    
- **Encapsulamento**: A estrutura interna é “escondida”, e o acesso ocorre apenas por meio das operações definidas.
    
- **Exemplos de operações**: criação, inserção, remoção, consulta, etc.
    

### **2. Vantagens do uso de TAD**

- **Reutilização**: Uma vez implementado e testado, pode ser usado em diferentes partes do programa ou em projetos distintos.
    
- **Manutenção facilitada**: Alterações na implementação não afetam o código que utiliza o TAD.
    
- **Segurança**: O programador não acessa os dados diretamente, evitando manipulação incorreta.
    
- **Abstração**: O programador só precisa conhecer as operações disponíveis, não a implementação.

### **3. Exemplo de TAD: Conta Bancária**

Um exemplo de TAD para **contas bancárias**, com:

- **Estrutura**: nome do cliente, número da conta, saldo.
    
- **Operações**: criar conta, depositar, sacar, transferir, extrato.
    

A implementação é dividida em:

- **Arquivo `.h`** (interface): declara a estrutura e os protótipos das funções.
    
- **Arquivo `.c`** (implementação): contém a lógica das operações.
    
- **Programa principal**: usa as funções do TAD sem conhecer seus detalhes internos.
    

### **4. Exemplo de TAD: Conjunto (Set)**

Um **TAD conjunto** é uma coleção de elementos **sem repetição**. Operações básicas incluem:

- Inserção, remoção, união, interseção, busca, impressão.
    

A implementação segue a mesma lógica de separação entre interface (`conjunto.h`) e implementação (`conjunto.c`), com um programa principal que utiliza as operações definidas.

### **5. Conclusão**

O TAD é uma ferramenta fundamental para **organizar, encapsular e reutilizar código**, promovendo:

- **Clareza** no design de software.
    
- **Segurança** no acesso aos dados.
    
- **Flexibilidade** para alterações futuras.
    

Ele é amplamente utilizado em linguagens como C, C++, Java e Python (embora com diferentes mecanismos de abstração).
