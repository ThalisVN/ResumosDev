# Listas encadeadas duplas

## 1. **Introdução
A listas encadeadas duplas**, são uma estrutura de dados dinâmica em que cada elemento possui dois ponteiros: um para o elemento anterior e outro para o próximo. Isso permite a navegação bidirecional (do início ao fim e vice-versa), oferecendo maior flexibilidade em operações de inserção, remoção e consulta.

---

## 2. **Estrutura da Lista Encadeada Dupla**  
- Cada nó contém:  
  - Dados (ex.: `Aluno` com nome, nota, turma).  
  - Ponteiro para o nó anterior (`ant`).  
  - Ponteiro para o próximo nó (`prox`).  
- O primeiro nó tem `ant = NULL` e o último nó tem `prox = NULL`.  
- Um **descritor** (ou cabeçalho) armazena:  
  - Ponteiro para o primeiro nó.  
  - Ponteiro para o último nó.  
  - Contador de elementos.

---

## 3. **Operações Principais**  

### **3.1 Navegação**  
- Pode ser feita a partir do início (`prim`) ou do fim (`ult`).  
- Utiliza-se um laço de repetição para percorrer os nós.

### **3.2 Inserção**  
- Pode ser realizada:  
  - No início da lista.  
  - No fim da lista.  
  - Em posição intermediária.  
- É necessário ajustar os ponteiros `ant` e `prox` dos nós adjacentes.

### **3.3 Remoção**  
- Similar à inserção, pode ser no início, fim ou posição intermediária.  
- Deve-se liberar a memória do nó removido e reajustar os ponteiros.

### **3.4 Consulta e Atualização**  
- Requer navegação até o elemento desejado.  
- Não altera a estrutura dos ponteiros, apenas os dados armazenados.

## 4. **Vantagens e Aplicações**  
- **Flexibilidade**: navegação bidirecional.  
- **Dinamicidade**: tamanho variável em tempo de execução.  
- **Eficiência**: inserções e remoções são rápidas se o nó for conhecido.  
- Útil em aplicações como: histórico de navegação, listas de reprodução, edição de texto, entre outras.

---
## 5. **Conclusão**  
As listas encadeadas duplas são uma evolução das listas simplesmente encadeadas, oferecendo maior controle e eficiência em operações que exigem navegação reversa. Sua implementação, embora mais complexa, é amplamente utilizada em sistemas que necessitam de manipulação frequente e bidirecional de dados sequenciais.
