# **Pilhas (Stacks)**

## 1. **Introdução**  
As **pilhas** são estruturas de dados do tipo **LIFO (Last In, First Out)**, em que o último elemento inserido é o primeiro a ser removido. Podem ser implementadas de forma **estática** (com vetor de tamanho fixo) ou **dinâmica** (com alocação de memória sob demanda). São utilizadas em diversos contextos, como gerenciamento de chamadas de funções, histórico de navegação e avaliação de expressões.

---

## 2. **Características Principais**  
- Acesso restrito ao **topo** da pilha.  
- A extremidade oposta é chamada de **base**.  
- **Operações básicas**:  
  - **Push**: inserir no topo.  
  - **Pop**: remover do topo.  
  - **Top/Peek**: consultar o elemento do topo.  
- Pode ser implementada com **vetor (estática)** ou com **lista encadeada (dinâmica)**.

---

## 3. **Implementação Estática (Vetor)**  
**Estrutura**  
```c
#define MAX 100
struct aluno {
    int matricula;
    char nome[30];
    float n1, n2, n3;
};
typedef struct pilha Pilha;
struct pilha {
    int qtd;               // quantidade de elementos
    struct aluno dados[MAX];
};
```

 **Operações**  
- **Criação**: `Pilha* cria_Pilha()`  
- **Inserção (Push)**: `int insere_Pilha(Pilha* pi, struct aluno al)`  
- **Remoção (Pop)**: `int remove_Pilha(Pilha* pi)`  
- **Consulta do Topo**: `int consulta_topo_Pilha(Pilha* pi, struct aluno *al)`  
- **Verificação de estado**: `Pilha_cheia`, `Pilha_vazia`

---

## 4. **Implementação Dinâmica (Lista Encadeada)**  
**Estrutura**  
```c
typedef struct elemento {
    struct aluno dados;
    struct elemento *prox;
} Elem;

typedef struct pilha {
    Elem *topo;
} Pilha;
```

 **Operações**  
- **Criação**: aloca a estrutura da pilha e define `topo = NULL`.  
- **Inserção (Push)**: aloca um novo nó e o coloca no topo.  
- **Remoção (Pop)**: remove o nó do topo e libera memória.  
- **Consulta do Topo**: retorna os dados do elemento no topo sem removê-lo.

---
## 5. **Vantagens e Aplicações**  
- **Simplicidade**: fácil implementação e compreensão.  
- **Eficiência**: operações O(1) no topo.  
- **Aplicações comuns**:  
  - Gerenciamento de recursão e chamadas de função.  
  - Mecanismos de **desfazer/refazer** em editores.  
  - Avaliação de expressões pós-fixadas (notação polonesa).  
  - Controle de navegação em navegadores.

---

## 6. **Conclusão**  
As pilhas são estruturas fundamentais na computação, essenciais para situações que exigem processamento na ordem inversa de chegada. Suas implementações — estática e dinâmica — oferecem flexibilidade para diferentes necessidades de memória e desempenho, sendo amplamente utilizadas em algoritmos e sistemas computacionais.
