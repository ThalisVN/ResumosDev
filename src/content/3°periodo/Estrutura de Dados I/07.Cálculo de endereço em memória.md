# Cálculo de endereço em memória

## **1. Ponteiros e Alocação Dinâmica de Memória**
- **Ponteiro**: Variável que armazena **endereços de memória**.
- **Operadores básicos**:
  - `&`: Retorna o endereço de uma variável.
  - `*`: Na declaração indica um ponteiro; no uso acessa o conteúdo do endereço apontado.
- **Alocação dinâmica**: Memória alocada durante a execução do programa, na área **heap**.
- **Alocação estática vs. dinâmica**:
  - **Estática**: Tamanho definido em tempo de compilação (ex: vetores com tamanho fixo).
  - **Dinâmica**: Tamanho definido em tempo de execução (ex: uso de `malloc`, `calloc`).

---

## **2. Gerenciamento de Ponteiros**
- **Funções para alocação dinâmica** (biblioteca `stdlib.h`):
  - `malloc()`: Aloca um bloco de memória de tamanho especificado (em bytes). **Não inicializa** o conteúdo.
  - `calloc()`: Aloca memória para um vetor, **inicializando todos os elementos com zero**.
  - `realloc()`: Redimensiona um bloco de memória previamente alocado.
  - `free()`: Libera a memória alocada, prevenindo **vazamentos de memória**.

- **Exemplo de uso**:
  ```c
  int *ptr = (int*) malloc(n * sizeof(int));
  if (ptr == NULL) {
      // Tratamento de erro
  }
  // Uso do ponteiro
  free(ptr); // Liberação obrigatória
  ```

---

## **3. Aritmética com Ponteiros**
- **Incremento/decremento**: Avança/recua o ponteiro em unidades do **tipo de dado apontado**.
  - Ex: `ptr++` em um `int*` avança 4 bytes (tamanho de um `int` em muitas arquiteturas).
- **Operações relacionais**:
  - `==` e `!=`: Comparam se dois ponteiros apontam para o mesmo endereço.
  - `>`, `<`, `>=`, `<=`: Comparam posições relativas na memória (útil em vetores).
- **Exemplo prático**: Percorrer um vetor usando ponteiros:
  ```c
  for (int *p = vetor; p < vetor + n; p++) {
      printf("%d ", *p);
  }
  ```

---

## **4. Exemplos de Código**
- **Obter endereços**:
  ```c
  int a;
  printf("Endereço de a: %p\n", &a);
  ```
- **Ponteiro para inteiro**:
  ```c
  int *p;
  int x = 10;
  p = &x;
  printf("Valor apontado: %d\n", *p);
  ```
- **Alocação dinâmica de vetor**:
  ```c
  int *vetor = (int*) malloc(10 * sizeof(int));
  vetor[0] = 5; // Acesso como vetor comum
  free(vetor);
  ```

---

## **5. Importância na Estrutura de Dados**
- **Ponteiros** são fundamentais para estruturas como:
  - **Listas encadeadas**
  - **Árvores**
  - **Grafos**
- **Alocação dinâmica** permite estruturas que crescem/shrink conforme a necessidade, otimizando uso de memória.

---

## **6. Cuidados e Boas Práticas**
- **Sempre verificar** se `malloc`/`calloc` retornou `NULL` (falha na alocação).
- **Liberar memória** com `free()` para evitar vazamentos.
- **Não acessar ponteiros após liberação** (comportamento indefinido).
- **Evitar aritmética de ponteiros inválida** (ex: avançar além dos limites alocados).

---

## **Conclusão**
- **Ponteiros** são variáveis que armazenam endereços de memória.
- **Alocação dinâmica** permite gerenciar memória em tempo de execução.
- **Aritmética de ponteiros** facilita manipulação eficiente de vetores e estruturas complexas.
- **Dominar ponteiros** é essencial para implementar **estruturas de dados dinâmicas** e escrever código eficiente e flexível em C.
