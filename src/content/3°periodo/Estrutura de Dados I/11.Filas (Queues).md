# **Filas (Queues)**

## 1. **Introdução**  
As **filas** são estruturas de dados do tipo **FIFO (First In, First Out)**, em que o primeiro elemento inserido é o primeiro a ser removido. São amplamente utilizadas em sistemas computacionais para gerenciamento de processos, buffer de dados, sistemas de impressão e comunicação em rede. Podem ser implementadas de forma **estática** (com vetor) ou **dinâmica** (com lista encadeada).

---

## 2. **Características Principais**  
- Acesso restrito às **duas extremidades**:  
  - **Inserção (enfileirar)**: sempre no **final** (cauda).  
  - **Remoção (desenfileirar)**: sempre no **início** (frente).  
- **Operações básicas**:  
  - **Enqueue**: inserir no final.  
  - **Dequeue**: remover do início.  
  - **Front/Peek**: consultar o primeiro elemento.  
  - **Listagem**: exibir todos os elementos.  
- **Analogia comum**: fila de atendimento, onde o primeiro a chegar é o primeiro a ser atendido.

---

## 3. **Implementação Estática (Vetor)**  
- **Estrutura**  
```c
struct aluno {
    int matricula;
    char nome[15];
    int polo;
};
struct fila {
    struct aluno dados[MAX];
    int inicio, fim;
};
```

-  **Operações**  
	- **Inserção**: adiciona no índice `fim` e incrementa `fim`.  
	- **Remoção**: remove do índice `inicio` e incrementa `inicio`.  
	- **Consulta do primeiro**: retorna o elemento na posição `inicio`.  
	- **Listagem**: percorre de `inicio` a `fim-1`.

---

## 4. **Implementação Dinâmica (Lista Encadeada)**  
**Estrutura**  
```c
typedef struct no {
    int matricula;
    char nome[15];
    int polo;
    struct no *prox;
} TAluno;

struct fila {
    TAluno *inicio;
    TAluno *fim;
    int tam;
};
```

- **Operações**  
	- **Inserção**: cria novo nó, ajusta `fim->prox` e atualiza `fim`.  
	- **Remoção**: remove nó do `inicio`, atualiza `inicio` e libera memória.  
	- **Consulta do primeiro**: retorna dados do nó `inicio`.  
	- **Listagem**: percorre a lista a partir de `inicio`.

---
## 5. **Vantagens e Aplicações**  
- **Ordenação justa**: garante ordem de chegada.  
- **Eficiência**: operações O(1) nas extremidades.  
- **Aplicações comuns**:  
  - **Spoofing de impressão**: documentos aguardam na fila de impressão.  
  - **Gerenciamento de processos**: fila de pronto em sistemas operacionais.  
  - **Buffers de comunicação**: filas de mensagens em redes.  
  - **Atendimento ao cliente**: sistemas de senhas e filas de espera.

---

## 6. **Conclusão**  
As filas são estruturas essenciais para cenários que exigem processamento ordenado por chegada. Suas implementações — estática e dinâmica — permitem adaptação a diferentes necessidades de armazenamento e desempenho, sendo fundamentais em sistemas operacionais, redes e aplicações de gerenciamento de recursos.
