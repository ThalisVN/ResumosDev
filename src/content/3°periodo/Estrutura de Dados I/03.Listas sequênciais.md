# Listas sequenciais
## **1. Conceito de Listas Sequenciais**
- São estruturas que armazenam elementos de forma **linear e consecutiva** na memória.
- Também conhecidas como **listas lineares, estáticas lineares ou estáticas sequenciais**.
- Implementadas com **vetores**, com alocação **estática** de memória.

---

## **2. Características e Aplicações**
- **Indicadas para**:
  - Conjuntos de dados **pequenos e bem definidos**.
  - Inserções e remoções preferencialmente no **final da lista**.
- **Vantagens**:
  - Acesso direto por índices.
  - Tempo de acesso uniforme.
- **Desvantagens**:
  - Movimentação de elementos ao inserir/remover no meio.
  - Tamanho máximo pré-definido.

---

## **3. Classificação das Listas Sequenciais**
De acordo com o tipo de operação permitida, podem ser:
- **Fila (FIFO – First In, First Out)**: primeiro a entrar é o primeiro a sair.
- **Pilha (LIFO – Last In, First Out)**: primeiro a entrar é o último a sair.
- **Deque (Double Ended Queue)**: permite inserção e remoção em ambas as extremidades.

---

## **4. Operações Básicas em Listas Sequenciais**
As principais operações são implementadas por meio de funções:

- **Criação**: declaração do vetor.
- **Inicialização**: preparação da lista (`n = 0`).
- **Inserção**: adiciona elemento na posição `n`, se houver espaço.
- **Consulta (busca sequencial)**: percorre a lista para encontrar um valor.
- **Remoção**: remove elemento e desloca os demais para reorganizar.
- **Atualização**: localiza e altera o valor de um elemento.
- **Concatenação e Partição**: união ou divisão de listas.

---

## **5. Implementação em C**
Exemplos de funções em C:

- **Inserção**:
  ```c
  inserir(vetor, valor, n) {
    if (tamanho == n) "Lista cheia";
    else vetor[n] = valor; n++;
  }
  ```
- **Consulta**:
  ```c
  consultar(vetor, valor, n) {
    for (i = 0; i < n; i++)
      if (vetor[i] == valor) "Encontrado na posição i";
  }
  ```
- **Remoção**:
  ```c
  remover(vetor, valor, n) {
    pos = consultar(vetor, valor, n);
    if (pos != -1) desloca elementos a partir de pos;
  }
  ```
- **Atualização**:
  ```c
  atualizar(vetor, valor_antigo, valor_novo, n) {
    pos = consultar(vetor, valor_antigo, n);
    if (pos != -1) vetor[pos] = valor_novo;
  }
  ```
