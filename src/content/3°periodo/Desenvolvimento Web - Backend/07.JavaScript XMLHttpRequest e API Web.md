JavaScript XMLHttpRequest e API Web

## Introdução
O capítulo aborda o uso do **objeto XMLHttpRequest** em JavaScript para comunicação assíncrona entre cliente e servidor, além de apresentar conceitos sobre **APIs Web** e sua implementação prática.

---

## 1. Objeto JavaScript XMLHttpRequest
- Criado pela Microsoft para o Internet Explorer 4.0, hoje suportado por todos os navegadores modernos.
- Permite a **troca de dados entre cliente e servidor** sem recarregar a página (Ajax).
- **Sintaxe básica:**
  ```javascript
  var xhttp = new XMLHttpRequest();
  ```

### Métodos Principais:
| Método                     | Descrição                                                                 |
|----------------------------|---------------------------------------------------------------------------|
| `open(method, url, async)` | Especifica o tipo de requisição (GET/POST), URL e se é assíncrona.        |
| `send()`                   | Envia a requisição ao servidor.                                          |
| `setRequestHeader()`       | Define cabeçalhos HTTP (ex.: `Content-Type`).                            |
| `abort()`                  | Cancela a requisição.                                                    |

### Propriedades Principais:
| Propriedade          | Descrição                                 |
| -------------------- | ----------------------------------------- |
| `readyState`         | Estado da requisição (0 a 4).             |
| `status`             | Código HTTP (ex.: 200 OK, 404 Not Found). |
| `responseText`       | Resposta como texto.                      |
| `responseXML`        | Resposta como XML.                        |
| `onreadystatechange` | Função chamada quando `readyState` muda.  |

---

## 2. Métodos GET e POST
- **GET:** Usado para solicitar dados do servidor.
  ```javascript
  xhttp.open("GET", "demo_get.asp", true);
  xhttp.send();
  ```
- **POST:** Usado para enviar dados ao servidor.
  ```javascript
  xhttp.open("POST", "demo_post.asp", true);
  xhttp.send();
  ```

### Fluxo de Comunicação:
1. Cliente cria um objeto `XMLHttpRequest`.
2. Abre uma conexão com `open()`.
3. Define uma função de callback com `onreadystatechange`.
4. Envia a requisição com `send()`.
5. Servidor processa e retorna uma resposta.
6. Cliente atualiza a página com os dados recebidos.

---

## 3. APIs Web
- **API (Application Programming Interface):** Conjunto de regras e ferramentas para construir software.
- **Tipos de APIs Web:**
  - **APIs de Navegador:** Fornecidas pelo navegador (ex.: Web Audio API, Geolocation API).
  - **APIs de Terceiros:** Fornecidas por serviços externos (ex.: Twitter API, Google Maps API).

### Características:
- Abstraem complexidade.
- Permitem integração com serviços externos.
- Facilitam a criação de funcionalidades avançadas.

## 4. Construindo uma Aplicação com API

### Exemplo: Carregamento Assíncrono de Página
**Estrutura dos arquivos:**
- `principal.html`: Página principal com JavaScript.
- `pagina.html`: Página a ser carregada dinamicamente.
- `carregando.gif`: Imagem de loading.

#### Código HTML (`principal.html`):
```html
<HTML>
<HEAD>
    <TITLE>::XMLHttpRequest::</TITLE>
</HEAD>
<BODY>
    <DIV id="carregando"></DIV>
    <DIV id="urlContent">
        <a href="#" onclick="alteraURL('pagina.html');">Example</a>
    </DIV>
</BODY>
</HTML>
```

#### Código JavaScript:
```javascript
var xmlhttp = getXmlHttpRequest();

function getXmlHttpRequest() {
    if (window.XMLHttpRequest) {
        return new XMLHttpRequest();
    } else if (window.ActiveXObject) {
        return new ActiveXObject("Microsoft.XMLHTTP");
    }
}

function alteraURL(url) {
    document.getElementById("carregando").innerHTML = "<img src='carregando.gif'>";
    xmlhttp.open("POST", url, true);
    xmlhttp.onreadystatechange = function() {
        if (xmlhttp.readyState == 4) {
            document.getElementById("urlContent").innerHTML = xmlhttp.responseText;
            document.getElementById("carregando").innerHTML = "";
        }
    };
    xmlhttp.send(null);
}
```

### Funcionamento:
1. O usuário clica no link **"Example"**.
2. A função `alteraURL('pagina.html')` é chamada.
3. Exibe a imagem de carregamento.
4. Envia uma requisição POST assíncrona para `pagina.html`.
5. Ao receber a resposta (`readyState == 4`), o conteúdo é inserido na `div#urlContent`.
6. A imagem de carregamento é removida.

---

## Conclusão
- **XMLHttpRequest** é a base para **Ajax**, permitindo atualizações parciais de página.
- **APIs Web** ampliam as capacidades do JavaScript, integrando serviços externos e funcionalidades do navegador.
- O exemplo prático demonstra como criar uma **aplicação interativa** com carregamento assíncrono de conteúdo.
