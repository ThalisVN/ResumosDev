# JSON - AJAX

## 1. Conceito de JSON e AJAX
- **JSON (JavaScript Object Notation):** Formato leve de intercâmbio de dados, nativo do JavaScript, com menor overhead que XML.
- **AJAX (Asynchronous JavaScript and XML):** Técnica para criar aplicações web assíncronas, permitindo envio e recuperação de dados sem recarregar a página.
- **Combinação:** AJAX usa JSON para transferir dados entre cliente e servidor de forma eficiente.

---

## 2. Trabalhando com JSON em JavaScript

### Criando e Acessando Objetos JSON
```javascript
let contatos = {
    nome: "João",
    idade: 35,
    endereco: {
        rua: "Avenida Brasil",
        cidade: "Porto Alegre"
    },
    interesses: ["cozinhar", "correr"]
};

// Acesso por notação de ponto
contatos.nome; // "João"
contatos.endereco.rua; // "Avenida Brasil"
contatos.interesses[0]; // "cozinhar"
```

### Conversão entre Objetos e Strings
- **`JSON.stringify()`:** Converte objeto JavaScript em string JSON
- **`JSON.parse()`:** Converte string JSON em objeto JavaScript

```javascript
let objeto = {nome: "João", idade: 35};
let stringJSON = JSON.stringify(objeto); // '{"nome":"João","idade":35}'
let objetoNovo = JSON.parse(stringJSON); // {nome: "João", idade: 35}
```

## 3. Acessando JSON via AJAX (XMLHttpRequest)

### Exemplo: Carregar JSON de Arquivo Externo
```javascript
let request = new XMLHttpRequest();
request.open('GET', 'users.json', true);

request.onload = function() {
    let users = JSON.parse(this.response);
    let output = '';
    
    for(let i = 0; i < users.length; i++) {
        output += '<li>' + users[i].nome + ' tem ' + users[i].idade + ' anos</li>';
    }
    
    document.getElementById('users').innerHTML = output;
};

request.send();
```

### Estrutura do Arquivo `users.json`:
```json
[
    {"nome": "João", "idade": 35},
    {"nome": "Maria", "idade": 29},
    {"nome": "Cristiano", "idade": 54}
]
```

## 4. Exemplo Prático: Busca Assíncrona com ASP.NET MVC

### Front-end (HTML/JavaScript)
```html
<input type="text" id="Busca" name="Busca" onblur="buscaAjax();" />
<div id="retorno"></div>

<script>
function buscaAjax() {
    let texto = $('#Busca').val();
    
    $.ajax({
        url: '/Home/Busca',
        type: 'POST',
        data: { textoDigitado: texto },
        success: function(dados) {
            // Processa dados JSON retornados
            $('#retorno').html(formatarResultados(dados));
        }
    });
}
</script>
```

### Back-end (Controller ASP.NET MVC)
```csharp
[HttpPost]
public ActionResult Busca(string textoDigitado)
{
    // Simulação de banco de dados
    var contatos = new List<Contato> {
        new Contato { Nome = "Fernando", Sobrenome = "Klein" },
        new Contato { Nome = "Alan", Sobrenome = "Silva" },
        new Contato { Nome = "Carla", Sobrenome = "Vieira" }
    };
    
    // Filtra resultados
    var retorno = contatos
        .Where(c => c.Nome.ToLower().Contains(textoDigitado.ToLower()))
        .ToList();
    
    // Retorna JSON
    return Json(retorno);
}
```

## 5. Comparação: JSON vs XML

### Exemplo de Dados Equivalentes

**XML:**
```xml
<artistas>
  <nome_artista>Anitta</nome_artista>
  <formacao>2010</formacao>
  <albums>
    <album>
      <nome_album>Ritmo Perfeito</nome_album>
      <ano>2014</ano>
      <genero>Funk</genero>
    </album>
  </albums>
</artistas>
```

**JSON:**
```json
{
  "artistas": [{
    "nome_artista": "Anitta",
    "formacao": "2010",
    "albuns": [{
      "nome_album": "Ritmo Perfeito",
      "ano": "2014",
      "genero": "Funk"
    }]
  }]
}
```

## 6. Vantagens e Desvantagens

| Aspecto | JSON | XML |
|---------|------|-----|
| **Tamanho** | Menor (sem tags redundantes) | Maior (tags de abertura/fechamento) |
| **Legibilidade** | Mais simples, próximo à sintaxe JavaScript | Estruturado, hierárquico, fácil para humanos |
| **Metadados** | Limitado (precisa ser incluído como dado) | Nativo (atributos em elementos) |
| **Aprendizado** | Fácil (sintaxe simples) | Mais complexo (regras de tags, atributos) |
| **Processamento** | Rápido (nativo em JavaScript) | Mais lento (parser necessário) |
| **Validação** | Precisa de esquemas externos | Suporte nativo (XML Schema, DTD) |

---

## 7. Vantagens da Combinação AJAX + JSON
- **Performance:** Menor overhead de dados, transferência mais rápida
- **Experiência do usuário:** Atualizações parciais sem recarregar página
- **Integração:** Fácil manipulação no JavaScript (formato nativo)
- **Flexibilidade:** Ideal para APIs RESTful e aplicações SPA
- **Compatibilidade:** Suportado por todas as linguagens modernas

---

## 8. Conclusão
- **JSON** é o formato preferencial para transferência de dados em aplicações web modernas
- **AJAX** permite comunicação assíncrona, melhorando a experiência do usuário
- A combinação **AJAX + JSON** oferece performance superior ao tradicional **AJAX + XML**
- A escolha entre JSON e XML depende do contexto: JSON para APIs e transferência de dados, XML para documentos estruturados com metadados
- Frameworks como jQuery simplificam a implementação de chamadas AJAX com JSON
