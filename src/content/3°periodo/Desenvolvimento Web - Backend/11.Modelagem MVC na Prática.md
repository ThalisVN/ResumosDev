# Modelagem MVC na Prática 

---

## 1. Conceito do ASP.NET Framework MVC
- **Framework MVC:** Conjunto de bibliotecas, serviços e aplicativos para desenvolvimento de sistemas web.
- **Funcionalidades principais:**
  - Fornecimento de bibliotecas de código reutilizáveis e testados.
  - Padronização que atende às melhores práticas do mercado.
- **Arquitetura MVC:**
  - **Model:** Classes que representam tabelas do banco de dados.
  - **View:** Interfaces que exibem dados para o usuário.
  - **Controller:** Faz a ligação entre Model e View.

---

## 2. Desenvolvendo a Camada Model
- **Model:** Representa as classes que mapeiam tabelas do banco de dados.
- **Criação do projeto no Visual Studio:**
  1. Criar **Aplicativo Web ASP.NET (.NET Framework)** com C#
  2. Selecionar modelo **MVC**
  3. Estrutura de pastas é criada automaticamente

### Exemplo: Classe `Tema` (Model)
```csharp
[Table("Tema")]
public class Tema
{
    [Column("tem_id")]
    public int ID { get; set; }
    public string Tem_descricao { get; set; }
    public DateTime Tem_momento { get; set; }
    public string Usu_login { get; set; }
}
```

### Configuração do Entity Framework para MySQL
- Instalar pacote: **MySQL.Data.EntityFramework for EF6**
- Classe de contexto (`TemaDBContext`) gerencia a conexão com o banco:
```csharp
[DbConfigurationType(typeof(MySqlEFConfiguration))]
public class TemaDBContext : DbContext
{
    public DbSet<Tema> Temas { get; set; }
    public TemaDBContext() : base("DefaultConnection") { }
}
```

### Configuração da Conexão no `Web.config`
```xml
<connectionStrings>
  <add name="DefaultConnection"
    providerName="MySql.Data.MySqlClient"
    connectionString="server=localhost;port=3308;userid=root;
    password=admin;database=db_forum;persistsecurityinfo=True"/>
</connectionStrings>
```

## 3. Programando a Camada Controller
- **Controller:** Faz a ligação entre Views e Model, acessando dados via Entity Framework.
- **Criação do controlador:**
  1. Clicar com botão direito em **Controllers** → **Adicionar** → **Controlador**
  2. Selecionar **Controlador MVC 5 com modos de exibição usando Entity Framework**
  3. Escolher classe do modelo (`Tema`) e classe de contexto (`TemaDBContext`)
  4. Nomear como `TemasController`

### Métodos CRUD Gerados Automaticamente
```csharp
public class TemasController : Controller
{
    private TemaDBContext db = new TemaDBContext();
    
    public ActionResult Index()
    {
        return View(db.Temas.ToList());
    }
    // Outros métodos: Details, Create, Edit, Delete
}
```

### Rotas Configuradas (`App_Start/RouteConfig.cs`)
```csharp
routes.MapRoute(
    name: "Default",
    url: "{controller}/{action}/{id}",
    defaults: new { controller = "Home", action = "Index", 
                    id = UrlParameter.Optional }
);
```

### URLs de Acesso aos Métodos
- **Listar:** `https://localhost:44335/Temas/Index`
- **Criar:** `https://localhost:44335/Temas/Create`
- **Editar registro 1:** `https://localhost:44335/Temas/Edit/1`
- **Excluir registro 2:** `https://localhost:44335/Temas/Delete/2`
- **Detalhes registro 4:** `https://localhost:44335/Temas/Details/4`

## 4. Implementando a Camada View
- **Views:** Formulários baseados no mecanismo **Razor** para manipulação de dados.
- **Arquivos gerados automaticamente na pasta `Views/Temas/`:**
  - `Create.cshtml`: Formulário para inserir novos temas
  - `Index.cshtml`: Listagem de temas cadastrados
  - `Edit.cshtml`: Formulário para atualizar temas
  - `Delete.cshtml`: Confirmação de exclusão de temas

### Exemplo de Código Razor em `Index.cshtml`
```html
@model IEnumerable<ForumWeb.Models.Tema>

<h2>Index</h2>
<p>@Html.ActionLink("Criar novo tema", "Create")</p>

<table>
    <tr>
        <th>@Html.DisplayNameFor(model => model.Tem_descricao)</th>
        <th>@Html.DisplayNameFor(model => model.Tem_momento)</th>
        <th>@Html.DisplayNameFor(model => model.Usu_login)</th>
    </tr>
    
    @foreach (var item in Model)
    {
        <tr>
            <td>@Html.DisplayFor(modelItem => item.Tem_descricao)</td>
            <td>@Html.DisplayFor(modelItem => item.Tem_momento)</td>
            <td>@Html.DisplayFor(modelItem => item.Usu_login)</td>
            <td>
                @Html.ActionLink("Editar", "Edit", new { id = item.ID }) |
                @Html.ActionLink("Detalhes", "Details", new { id = item.ID }) |
                @Html.ActionLink("Excluir", "Delete", new { id = item.ID })
            </td>
        </tr>
    }
</table>
```

### Personalização com DataAnnotations
```csharp
[Display(Name = "Descrição do tema")]
public string Tem_descricao { get; set; }
```

---

## 5. Fluxo Completo MVC
1. **Usuário acessa URL** → Roteamento direciona para controller apropriado
2. **Controller** acessa dados via Model (Entity Framework)
3. **Model** retorna dados do banco de dados
4. **Controller** passa dados para View
5. **View** renderiza HTML com dados recebidos
6. **Resposta HTML** é enviada ao navegador do usuário

---

## 6. Conclusão
- O **ASP.NET Framework MVC** facilita o desenvolvimento web seguindo o padrão arquitetural MVC.
- **Entity Framework** simplifica o acesso a dados, eliminando a necessidade de SQL manual.
- **Scaffolding** gera automaticamente código CRUD para models, controllers e views.
- **Razor** fornece sintaxe eficiente para misturar HTML com código C# nas views.
- A **estrutura organizada** em pastas (Models, Views, Controllers) promove separação de responsabilidades e manutenibilidade.
