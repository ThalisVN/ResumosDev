Tipos de dados JSON

## Introdução
- JSON (JavaScript Object Notation) é um formato leve de troca de dados, baseado em texto e independente de linguagem.
- É amplamente usado em APIs e aplicações web devido à sua simplicidade e legibilidade.

## Tipos de Dados JSON
JSON suporta dois grandes grupos de tipos de dados:

### 1. **Dados Elementares (Primitivos)**
- Não podem ser decompostos.
- Principais tipos:
  - **String**: Sequência de caracteres (`"texto"`).
  - **Number**: Números inteiros ou reais (`10`, `3.14`).
  - **Boolean**: Valores lógicos (`true` ou `false`).
  - **Null**: Valor nulo (`null`).

### 2. **Dados Estruturados (Compostos)**
- São combinações de tipos primitivos ou outros estruturados.
- Principais estruturas:
  - **Objeto**: Coleção de pares `chave: valor` entre chaves `{}`.
    ```json
    { "nome": "João", "idade": 25 }
    ```
  - **Array**: Lista ordenada de valores entre colchetes `[]`.
    ```json
    [ "maçã", "banana", "laranja" ]
    ```

## Modelos JSON – Exemplos
### Exemplo 1: Glossário em JSON (com objetos aninhados)
```json
{
  "glossary": {
    "title": "exemplo de glossário",
    "GlossDiv": {
      "title": "Glossário JSON",
      "GlossList": {
        "GlossEntry": {
          "ID": "SGML",
          "GlossTerm": "Standard Generalized Markup Language",
          "Acronym": "SGML"
        }
      }
    }
  }
}
```

### Exemplo 2: Menu com booleanos e arrays
```json
{
  "menu": {
    "header": "SVG Viewer",
    "items": [
      { "id": "Open", "label": "Abrir" },
      { "id": "Save", "label": "Salvar" },
      null,
      { "id": "ZoomIn", "label": true },
      { "id": "ZoomOut", "label": false }
    ]
  }
}
```

## Aplicação Prática: Conversão de Objeto Java para JSON
### Classe `BMW` (POJO – Plain Old Java Object)
```java
public class BMW {
    private Long id;
    private String modelo;
    private String placa;
    // getters e setters
}
```

### Classe `AplicacaoJSON` – Conversão para JSON
```java
import org.json.JSONObject;

public class AplicacaoJSON {
    public static void main(String[] args) {
        BMW bmw = new BMW();
        bmw.setId(1L);
        bmw.setModelo("320i");
        bmw.setPlaca("SFT1456");

        JSONObject bmwJson = new JSONObject();
        bmwJson.put("id", bmw.getId());
        bmwJson.put("Modelo", bmw.getModelo());
        bmwJson.put("Placa", bmw.getPlaca());

        System.out.println(bmwJson.toString());
        // Saída: {"id":1,"Modelo":"320i","Placa":"SFT1456"}
    }
}
```

## Vantagens e Limitações do JSON
### ✅ Vantagens:
- Simples, legível e leve.
- Independente de linguagem.
- Fácil de criar, manipular e analisar.
- Suportado nativamente em JavaScript.

### ❌ Limitações:
- Não suporta hipermídia (imagens, vídeos) diretamente.
- Pode haver conflitos de chaves em dados de múltiplas fontes.
- Validação limitada (não possui esquemas como XML DTD/XSD).

## Conclusão
- JSON é um formato essencial para **intercâmbio de dados** em aplicações modernas.
- Compreender seus **tipos de dados** (primitivos e estruturados) é fundamental para modelar informações corretamente.
- A conversão de objetos de linguagens como Java para JSON é uma prática comum em APIs RESTful.
