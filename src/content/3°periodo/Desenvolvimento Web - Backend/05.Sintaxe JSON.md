# Sintaxe JSON
## Introdução
O capítulo aborda o formato **JSON (JavaScript Object Notation)**, sua sintaxe e uma comparação com o **XML**, destacando suas aplicações e vantagens no intercâmbio de dados.

## Importância do JSON
- **JSON** é um formato leve para troca de dados, derivado da sintaxe do JavaScript, mas independente de linguagem.
- Surgiu como uma alternativa mais simples e eficiente ao **XML**, especialmente em sistemas web.
- **Vantagens do JSON sobre XML**:
  - Mais leve e de fácil leitura.
  - Parsing mais simples (função JavaScript nativa).
  - Suporta objetos e arrays nativamente.
  - Mais rápido na execução e transporte.
  - Amplamente adotado por grandes empresas (Google, Facebook, Amazon, etc.).

### Exemplo Comparativo:
- **XML**:
  ```xml
  <?xml version="1.0" encoding="UTF-8"?>
  <id>1</id>
  <nome>João Maria</nome>
  <endereco>Fortaleza</endereco>
  ```
- **JSON**:
  ```json
  {"id":1,"nome":"João Maria","endereco":"Fortaleza"}
  ```

## JSON vs XML
### Principais Diferenças:
| Aspecto               | XML                                      | JSON                                     |
|-----------------------|------------------------------------------|------------------------------------------|
| **Origem**            | Extensible Markup Language               | JavaScript Object Notation               |
| **Sintaxe**           | Similar a HTML                           | Similar a objetos JavaScript             |
| **Parsing**           | Requer parser XML                        | Basta função JavaScript                  |
| **Validação**         | Possui DTD/XSD para validação estrutural | Validação apenas da forma (cabe à aplicação) |
| **Legibilidade**      | Menos legível                            | Mais legível                             |
| **Orientação**        | Orientado a documento                    | Orientado a objeto                       |
| **Segurança**         | Maior segurança                          | Menor segurança                          |
| **Exibição no navegador** | Pode ser exibido diretamente           | Requer análise (parsing) para exibição   |

### Exemplo com Array/Vetor:
- **XML** (repetitivo):
  ```xml
  <Time>
    <Jogador>
      <primeiroNome>Cristiano</primeiroNome>
      <ultimoNome>Ronaldo</ultimoNome>
    </Jogador>
    ...
  </Time>
  ```
- **JSON** (compacto):
  ```json
  "Time": [
    {"primeiroNome":"Cristiano","ultimoNome":"Ronaldo"},
    {"primeiroNome":"Lionel","ultimoNome":"Messi"},
    {"primeiroNome":"Daniel","ultimoNome":"Alves"}
  ]
  ```

## Estruturas do JSON
1. **Objeto**: Coleção de pares **nome/valor** (ex.: `{"chave": "valor"}`).
2. **Array**: Lista ordenada de valores (ex.: `[1, 2, 3]`).

Essas estruturas são universais e suportadas pela maioria das linguagens.

## Sintaxe do JSON – Exemplo Prático
Exemplo de um menu de restaurante em JSON:

```json
{
  "type": "Restaurante Menu",
  "restaurante-info": {
    "id": "121721",
    "name": "Restaurante Brasil",
    "address": "Rio de Janeiro, Copacabana, Q.10",
    "rating": "0.00",
    "payment-methods": [
      {"id": "10", "type": "Cartão de débito"},
      {"id": "30", "type": "Cartão de crédito"}
    ]
  },
  "Menu-Pratos": [
    {"id": "2", "name": "Macarrão com camarão internacional"},
    {"id": "3", "name": "Peixe nordestino assado"}
  ]
}
```

## Conclusão
- **JSON** é mais leve, simples e rápido que o XML.
- É ideal para APIs web e troca de dados entre cliente e servidor.
- Sua sintaxe é baseada em objetos e arrays, facilitando a integração com JavaScript e outras linguagens.
- Embora não tenha validação nativa como o XML, sua simplicidade e eficiência o tornaram padrão na web moderna.
