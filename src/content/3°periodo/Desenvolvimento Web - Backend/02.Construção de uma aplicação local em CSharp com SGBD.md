# Construção de uma aplicação local em C# com SGBD

## Introdução
- **C#** é uma linguagem de programação amplamente usada no meio acadêmico e comercial, parte do ecossistema .NET.
- **MySQL** é um SGBD popular, utilizado para criar e gerenciar bancos de dados de diversos portes.
- Este capítulo ensina a construir uma **aplicação desktop em C#** que se conecta a um banco de dados MySQL.

## Construindo a Aplicação em C#

### Características do C#:
- Orientada a componentes e objetos.
- Fortemente tipada.
- Gerenciada por *Garbage Collector*.
- Multiplataforma (.NET Core suporta Windows, macOS e Linux).

### Ambiente de Desenvolvimento:
- **Visual Studio 2019 (Community)** – IDE recomendada.
- Tipo de projeto: **Windows Forms (.NET Framework)**.

### Protótipo da Aplicação:
- Aplicação de **Cadastro de Empregado** com os campos:
  - Matrícula (automática, chave primária)
  - CPF (único)
  - Nome
  - Endereço
- Botões: Pesquisar, Salvar, Excluir, Limpar.
- Elementos visuais: `Label`, `TextBox`, `Button`, `DataGridView`.

## Manipulando o Banco de Dados

### Estrutura do Banco:
- Tabela `empregado` com os campos mencionados.
- Chave primária autoincrementada (`AI`), CPF com restrição única (`UQ`).

### Classe `Empregado.cs`:
- Contém atributos correspondentes aos campos da tabela.
- Inclui métodos para:
  - `Pesquisar()` – retorna `DataTable` com registros.
  - `Incluir()`, `Alterar()`, `Excluir()` – operações CRUD.
- Utiliza `MySqlConnection` para conexão com o banco.
- Previne **SQL Injection** com parâmetros tipados (`AddWithValue`).

### Conexão com MySQL:
- String de conexão exemplo:
  ```csharp
  "SERVER=localhost;PORT=3308;DATABASE=db_empregado;UID=root;PWD=admin"
  ```

### Arquivo `FormLocal.cs`:
- Contém a lógica dos eventos dos botões.
- Exemplo do método `Pesquisar()` no formulário:
  ```csharp
  private void Pesquisar()
  {
      Empregado emp = new Empregado();
      emp.Matricula = Convert.ToInt32(textMatricula.Text);
      emp.Cpf = textCpf.Text;
      emp.Nome = textNome.Text;
      dataGridViewEmpregado.DataSource = emp.Pesquisar();
  }
  ```
