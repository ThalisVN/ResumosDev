Raciocínio Lógico

### **Introdução**  
A programação de computadores exige **raciocínio lógico** para traduzir problemas do mundo real em algoritmos. Esse raciocínio estrutura-se em premissas e conclusões, como no exemplo clássico:  
- *Premissa 1*: Todo ser humano é mortal.  
- *Premissa 2*: Pelé é um ser humano.  
- *Conclusão*: Logo, Pelé é mortal.  

A lógica é a base para organizar informações, resolver problemas e construir sistemas computacionais.  

### **Lógica Aristotélica**  
Aristóteles estabeleceu três princípios fundamentais:  
1. **Identidade**: "A é A" (ex.: "Cachorros são cachorros").  
2. **Não Contradição**: Duas afirmações contraditórias não podem ser verdadeiras simultaneamente.  
3. **Terceiro Excluído**: Uma proposição só pode ser **verdadeira** ou **falsa**, sem meio-termo.  

**Silogismo**: Estrutura dedutiva com premissa maior, premissa menor e conclusão
### **Lógica Matemática**  
Desenvolvida por Frege, usa símbolos e tabelas-verdade para analisar proposições.  

#### **Conectivos Lógicos**  
| Símbolo | Nome          | Exemplo (Português)   |     |
| ------- | ------------- | --------------------- | --- |
| `~`     | Negação       | "Não p"               |     |
| `∧`     | Conjunção     | "p e q"               |     |
| `∨`     | Disjunção     | "p ou q"              |     |
| `→`     | Condicional   | "Se p, então q"       |     |
| `↔`     | Bicondicional | "p se e somente se q" |     |

**Exemplos**:  
- **Conjunção (`∧`)**: "5 + 4 = 9 ∧ 4 + 13 = 12" → **Falso** (uma proposição é falsa).  
- **Condicional (`→`)**: "Se 3*0 = 2, então 2 + 5 = 3" → **Verdadeiro** (ambas falsas).  

 **Tabelas-Verdade**  
- **Negação**: Inverte o valor lógico.  
- **Conjunção**: Verdadeira apenas se ambas proposições forem verdadeiras.  
- **Disjunção**: Verdadeira se pelo menos uma proposição for verdadeira.  



### **Linguagem Natural vs. Artificial**  
| **Linguagem Natural**                        | **Linguagem Artificial**                                 |     |
| -------------------------------------------- | -------------------------------------------------------- | --- |
| Desenvolvida organicamente (ex.: português). | Criada com regras precisas (ex.: código de programação). |     |
| Ambígua (ex.: "Ele viu o livro com óculos"). | Padronizada (ex.: fórmulas matemáticas).                 |     |

**Aplicação em Computação**:  
- **Máquina de Turing** (Alan Turing): Modelo teórico que simula algoritmos, base dos computadores modernos.  
- **Processamento de Linguagem Natural (PLN)**: Traduz linguagem humana em comandos para máquinas.  

### **Proposições**  
**Proposição Simples**: Declaração única, verdadeira ou falsa.  
- Exemplo: "Vinicius gosta de cachorros."  

**Proposição Composta**: Combinação de proposições simples com conectivos.  
- Exemplo: "Eu gosto de praia **e** de rio." (Conjunção).  

### **Análise com Teoria de Conjuntos**  
- **Conectivo "e" (`∧`)**: Interseção de conjuntos (ex.: pessoas que gostam de praia **e** rio).  
- **Conectivo "ou" (`∨`)**: União de conjuntos (ex.: viajar de carro **ou** avião).  

### **Aplicações na Computação**  
1. **Algoritmos**: Sequências lógicas para resolver problemas (ex.: ordenar dados).  
2. **Inteligência Artificial**: Sistemas baseados em regras lógicas para tomada de decisões.  
3. **Criptografia**: Lógica matemática para codificar e decodificar informações (ex.: máquina Enigma na WWII).  

### **Conclusão**  
A lógica é a espinha dorsal da programação, permitindo estruturar pensamentos, validar argumentos e criar sistemas eficientes. Dominar conectivos lógicos, proposições e a relação entre linguagens natural/artificial é essencial para desenvolver soluções tecnológicas robustas.
