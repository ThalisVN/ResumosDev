## Estruturas de controle condicional

### **Introdução**  
As estruturas condicionais (**if**, **else**, **elif**) são essenciais para controlar o fluxo de execução de um programa, permitindo tomar decisões com base em condições. Em Python, essas estruturas são intuitivas e seguem uma sintaxe clara, mas exigem atenção à **indentação** para definir blocos de código.  

### **Tipos de Estruturas Condicionais**  

#### **1. Estrutura Simples (IF)**  
- Executa um bloco de código **apenas se a condição for verdadeira**.  
- **Sintaxe**:  
  ```python
  if condição:
      # Bloco de código executado se a condição for True
  ```  
- **Exemplo**:  
  ```python
  idade = 20
  if idade >= 18:
      print("Maior de idade")  # Saída: "Maior de idade"
  ```  

#### **2. Estrutura Composta (IF-ELSE)**  
- Define ações para **casos verdadeiros (if)** e **falsos (else)**.  
- **Sintaxe**:  
  ```python
  if condição:
      # Bloco executado se True
  else:
      # Bloco executado se False
  ```  
- **Exemplo**:  
  ```python
  temperatura = 30
  if temperatura > 25:
      print("Dia quente")
  else:
      print("Dia frio")  # Saída: "Dia quente"
  ```  

#### **3. Estrutura Encadeada (IF-ELIF-ELSE)**  
- Avalia **múltiplas condições** em sequência.  
- **elif** ("else if") verifica condições adicionais após o **if**.  
- **Sintaxe**:  
  ```python
  if condição1:
      # Bloco 1
  elif condição2:
      # Bloco 2
  else:
      # Bloco padrão
  ```  
- **Exemplo**:  
  ```python
  nota = 85
  if nota >= 90:
      print("A")
  elif nota >= 80:
      print("B")  # Saída: "B"
  elif nota >= 70:
      print("C")
  else:
      print("Reprovado")
  ```  

### **Erros Comuns**  
| **Erro**                | **Solução**                          |  
|-------------------------|--------------------------------------|  
| Esquecer **:** após `if`| Adicione `:` no final da condição.   |  
| Indentação inconsistente | Use 4 espaços em todos os blocos.    |  
| Condições redundantes    | Use `elif` para evitar verificações desnecessárias. |  

---

### **Conclusão**  
As estruturas condicionais são fundamentais para criar programas dinâmicos e responsivos. Em Python, a clareza sintática (com **if**, **elif**, **else**) e a ênfase em indentação tornam o código mais legível e organizado. Pratique com cenários reais (ex: sistemas de login, análises de dados) para dominar esses conceitos!
