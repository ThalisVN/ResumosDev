## Álgebra Booleana
### **Introdução**  
A computação opera em **lógica binária** (0 e 1), correspondendo a **falso (F)** e **verdadeiro (V)**. A **Álgebra de Boole**, criada por George Boole, é a base matemática para operações lógicas em circuitos digitais e programação. Ela simplifica a representação de decisões e operações em sistemas computacionais.  

### **Teoremas Fundamentais da Álgebra de Boole**  
Principais postulados e teoremas para variáveis booleanas (`p`, `q`, `r`):  

| **Teorema/Postulado**   | **Expressão**                     | **Exemplo**                           |     |
| ----------------------- | --------------------------------- | ------------------------------------- | --- |
| **Identidade**          | `p ∨ F = p` e `p ∧ V = p`         | `F ∨ V = V` (Verdadeiro)              |     |
| **Complementação**      | `p ∨ ~p = V` e `p ∧ ~p = F`       | "Ana viajou ou não viajou" = Sempre V |     |
| **Idempotência**        | `p ∨ p = p` e `p ∧ p = p`         | `V ∧ V = V`                           |     |
| **Elemento Absorvente** | `p ∨ V = V` e `p ∧ F = F`         | `F ∧ V = F`                           |     |
| **Leis de De Morgan**   | `~(p∨q) = ~p ∧ ~q`                | Negar "A ou B" = "Não A e Não B"      |     |
| **Distributiva**        | `p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r)` | Distribuição de operações             |     |
### **Conectivos Lógicos e Precedência**  
| **Conectivo** | **Símbolo** | **Operação** | **Precedência** | **Exemplo** |     |
| ------------- | ----------- | ------------ | --------------- | ----------- | --- |
| **NÃO**       | `~`         | Negação      | 1º              | `~V = F`    |     |
| **E**         | `∧`         | Conjunção    | 2º              | `V ∧ F = F` |     |
| **OU**        | `∨`         | Disjunção    | 3º              | `V ∨ F = V` |     |

**Ordem de precedência**: Parênteses > NÃO > E > OU.  
**Exemplo**:  
- `S = p ∧ ~(q ∨ r)`: Resolve `q ∨ r` primeiro, depois aplica `~` e, por fim, `∧`.  

### **Tabelas-Verdade**   
Mapeiam todas as combinações possíveis de entradas e saídas de uma expressão lógica.  
**Exemplo para `S = p ∧ q ∨ r`** (3 variáveis → 2³ = 8 linhas):  

| **p** | **q** | **r** | **p ∧ q** | **S = (p ∧ q) ∨ r** |     |
| ----- | ----- | ----- | --------- | ------------------- | --- |
| F     | F     | F     | F         | F                   |     |
| F     | F     | V     | F         | V                   |     |
| ...   | ...   | ...   | ...       | ...                 |     |
| V     | V     | V     | V         | V                   |     |

**Aplicação**: Usada para verificar equivalências lógicas e simplificar circuitos.  

### **Tautologias, Contradições e Contingências**  
| **Conceito**     | **Definição**                                 | **Exemplo**                              |     |
| ---------------- | --------------------------------------------- | ---------------------------------------- | --- |
| **Tautologia**   | Sempre verdadeira, independente das entradas. | `p ∨ ~p` ("Ana viajou ou não viajou")    |     |
| **Contradição**  | Sempre falsa, independente das entradas.      | `p ∧ ~p` ("Ana viajou e não viajou")     |     |
| **Contingência** | Resultado depende das entradas.               | `p ∨ q` ("Ana viajou de carro ou avião") |     |
### **Aplicações na Computação**  
1. **Circuitos Lógicos**: Portas AND, OR, NOT em hardware.  
2. **Programação**: Condicionais (`if`, `else`) e operadores lógicos (`&&`, `||`).  
3. **Criptografia**: Algoritmos baseados em operações booleanas.  
4. **Inteligência Artificial**: Lógica para tomada de decisões.  
### **Conclusão**  
A Álgebra de Boole é **essencial** para a computação, permitindo modelar problemas complexos em operações binárias. Seus conceitos sustentam desde circuitos eletrônicos até algoritmos avançados, sendo fundamental para qualquer profissional da área de TI.
