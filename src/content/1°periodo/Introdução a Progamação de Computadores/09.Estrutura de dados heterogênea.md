## Estrutura de dados heterogênea

Os dicionários (dict) são uma das estruturas de dados mais poderosas e versáteis em Python. Vamos consolidar os principais conceitos apresentados:

### Características Fundamentais
- **Estrutura heterogênea**: Armazena pares chave-valor de tipos diversos
- **Não ordenada**: Os elementos não têm uma ordem fixa (antes do Python 3.7)
- **Mutável**: Pode ser alterado após a criação
- **Chaves únicas**: Não pode haver duplicação de chaves

### Criação de Dicionários
```python
# Dicionário vazio
d1 = {}
d2 = dict()

# Dicionário com elementos
d3 = {'nome': 'Maria', 'idade': 25}
d4 = dict(nome='João', idade=30)

# Com tipos mistos
d5 = {1: 'um', 'dois': 2, (3,): [1, 2, 3]}
```

### Operações Básicas
```python
# Acesso
valor = d3['nome']  # 'Maria'

# Adição/Atualização
d3['email'] = 'maria@exemplo.com'
d3['idade'] = 26

# Verificação de existência
'idade' in d3  # True

# Tamanho
len(d3)  # 3

# Remoção
del d3['email']
valor = d3.pop('idade')  # 26
```

### Métodos Úteis
```python
# Obter todas chaves
chaves = d3.keys()  # dict_keys(['nome'])

# Obter todos valores
valores = d3.values()  # dict_values(['Maria'])

# Obter pares chave-valor
itens = d3.items()  # dict_items([('nome', 'Maria')])

# Obter valor com padrão
idade = d3.get('idade', 0)  # Retorna 0 se não existir

# Atualização em massa
d3.update({'cidade': 'SP', 'telefone': '99999999'})
```

### Técnicas Avançadas
#### Criação a partir de sequências
```python
nomes = ['Ana', 'Bruno', 'Carla']
idades = [25, 30, 28]
pessoas = dict(zip(nomes, idades))
# {'Ana': 25, 'Bruno': 30, 'Carla': 28}
```

#### Dict Comprehension
```python
quadrados = {x: x**2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Com condição
pares = {x: x*2 for x in range(10) if x % 2 == 0}
```

#### Contagem de Elementos
```python
from collections import defaultdict, Counter

# Contagem tradicional
contagem = {}
for letra in 'abracadabra':
    contagem[letra] = contagem.get(letra, 0) + 1

# Usando defaultdict
contagem = defaultdict(int)
for letra in 'abracadabra':
    contagem[letra] += 1

# Usando Counter (mais eficiente)
contagem = Counter('abracadabra')
```

### Tratamento de Erros
```python
try:
    print(d3['endereco'])  # Chave não existe
except KeyError:
    print("Chave não encontrada")

# Alternativa elegante
endereco = d3.get('endereco', 'Não informado')
```

### Considerações sobre Chaves
- Devem ser tipos imutáveis (strings, números, tuplas)
- Listas e outros dicionários não podem ser chaves
- A função `hash()` pode testar se um tipo é válido como chave

Dicionários são essenciais para:
- Representar estruturas de dados complexas
- Agrupar informações relacionadas
- Contagens e estatísticas
- Configurações e parâmetros
- Cache e memoização

A escolha entre listas e dicionários depende da natureza do problema: use listas para coleções ordenadas de itens similares e dicionários para associações entre chaves únicas e valores.
