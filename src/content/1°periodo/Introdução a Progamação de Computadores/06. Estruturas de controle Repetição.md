##  Estruturas de controle Repetição

### Introdução às Estruturas de Repetição

As estruturas de repetição (também chamadas de loops ou laços) são fundamentais em programação, permitindo executar um bloco de código múltiplas vezes. Python oferece principalmente duas estruturas:
- `for`: para iterar sobre sequências ou um número conhecido de vezes
- `while`: para repetir enquanto uma condição for verdadeira

### O Loop `for`

### Sintaxe básica:
```python
for valor in sequência:
    # bloco de código
```

### Exemplos práticos:

1. Iterando sobre uma lista:
```python
numeros = [1, 2, 3, 4, 5]
soma = 0
for num in numeros:
    soma += num
print(soma)  # Saída: 15
```

2. Usando `enumerate()` para obter índice e valor:
```python
frutas = ['maçã', 'banana', 'laranja']
for indice, fruta in enumerate(frutas):
    print(f"Índice {indice}: {fruta}")
```

3. Com `else` (executado ao final do loop, a menos que haja `break`):
```python
for i in range(3):
    print(i)
else:
    print("Loop completo")
```

### A Função `range()`

Gera sequências numéricas para controle de repetições:

```python
# range(início, fim, passo)
for i in range(5):         # 0 a 4
    print(i)

for i in range(2, 10, 2):  # 2, 4, 6, 8
    print(i)

for i in range(5, 0, -1):  # 5, 4, 3, 2, 1
    print(i)
```

### O Loop `while`

Repete enquanto uma condição for verdadeira:

### Sintaxe básica:
```python
while condição:
    # bloco de código
```

### Exemplos:

1. Contador básico:
```python
contador = 0
while contador < 5:
    print(contador)
    contador += 1
```

2. Fibonacci:
```python
a, b = 0, 1
while b < 100:
    print(b)
    a, b = b, a + b
```

3. Com `else`:
```python
tentativas = 3
while tentativas > 0:
    print(f"Tentativas restantes: {tentativas}")
    tentativas -= 1
else:
    print("Acabaram as tentativas")
```

### Controle de Fluxo em Loops

- `break`: interrompe imediatamente o loop
- `continue`: pula para a próxima iteração

### Exemplos:

1. Usando `break`:
```python
for num in range(10):
    if num == 5:
        break
    print(num)  # Imprime 0, 1, 2, 3, 4
```

2. Usando `continue`:
```python
for num in range(10):
    if num % 2 == 0:
        continue
    print(num)  # Imprime apenas ímpares: 1, 3, 5, 7, 9
```

### Considerações Importantes

1. Evitar loops infinitos com `while` garantindo que a condição eventualmente se torne falsa
2. Preferir `for` quando o número de iterações é conhecido
3. Cuidado com modificações de listas durante iteração
4. Python permite loops aninhados para trabalhar com estruturas multidimensionais

### Exemplo Prático Combinado

```python
# Encontrar números primos até um limite
limite = 50
primos = []

for num in range(2, limite + 1):
    for divisor in range(2, int(num ** 0.5) + 1):
        if num % divisor == 0:
            break
    else:
        primos.append(num)

print("Números primos até", limite, ":", primos)
```

Este exemplo demonstra:
- Uso de `for` com `range()`
- Loop aninhado
- Cláusula `else` do `for`
- Uso de `break` para otimização

As estruturas de repetição são ferramentas poderosas que, quando bem compreendidas, permitem resolver problemas complexos de forma eficiente.
