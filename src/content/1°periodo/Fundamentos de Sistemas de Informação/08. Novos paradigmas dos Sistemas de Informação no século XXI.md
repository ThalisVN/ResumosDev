## Novos paradigmas dos Sistemas de Informação no século XXI
### Introdução 
Os profissionais de TI desempenham um papel crucial na adoção de tecnologias que impulsionam a competitividade empresarial.
### Business Intelligence (BI)
* Conceito: BI é um conjunto de metodologias e ferramentas que transformam dados em conhecimentos para apoio à decisão estratégica, gerando vantagens competitivas.
* Objetivo: Analisar dados históricos em tempo real para insights que otimizam o desempenho organizacional.
* Componentes principais:
	* Data Warehouse (DW): Repositório central de dados integrados, não voláteis e orientados a assuntos, armazenados em formato dimensional para análise multidimensional.
	*  ETL (Extract, Transform, Load): Processo de extração, transformação e carga de dados de fontes heterogêneas (ERP, CRM) para o DW.
	* Ferramentas de análise: Dashboards, relatórios dinâmicos e data mining para visualização e exploração de dado

### Diferença entre sistemas transacionais e BI
| Caracteristicas | sistema transacionais       | soluções de BI             |
| --------------- | --------------------------- | -------------------------- |
| Objetivo        | Operações diárias (ex.:ERP) | decisões estratégicas      |
| granularidade   | alto detalhe(transações)    | dados agregados Histórico  |
| atualização     | constante(ex.: vendas)      | estável(foco em tedências) |
| Orientação      | aplicativo                  | usuario(analise ad hoc)    |
### Implementação BI
1. Identificar necessidades estratégicas.
2. Mapear fontes de dados (estruturados e não estruturados).
3. Coletar e integrar dados via ETL.
4. Escolher ferramentas de visualização (ex: Power BI, Tableau)
5. criar relatórios padrões e analises predativos
6. expandir para toda organização
### Ciência de dados e Inteligência artificial 
**Conceitos Chave**
* Inteligência artificial (IA): Sistemas que simulam inteligência humana (ex.: reconhecimento de padrões, previsões).
* aplicações: Diagnósticos médicos, automação de TI, Segurança cibernéticas.
* Ciência de dados Combina estatística, machine Learning, Big Data para extrair insights de dados complexos.
* Big Data: Caracterizado pelos 3Vs.
	* Volume (ex. pentabytes de dados).
	* Variedade dados estruturados, textos, vídeos)
	* Velocidade de processamento em tempo real
* Exemplos práticos
	* Analise de redes Sociais: Identificação de padrões em 265 milhões de tweets para entender comportamentos.
	* Medicina: Robôs cirúrgicos (ex. Da davic) IA para reduzir tempo de recuperação em 21%.
	* previsões: Meteorológica, manutenção preventiva de equipamentos

### Computação móvel
**Definição:**
* Uso de dispositivos portáteis(smartphones, tablets) e redes sem fio para acessar a sistemas em qualquer lugar
* Tecnologias: 5G, IoT, Geolocalização
* Aplicações
	* Smart Cities:
		* Gestão de trafego em tempo real(ex.: detecção de acidentes via GPS)
		* estacionamento inteligente com leitura de QR code
	* Saúde:
		* leitura de medidores de agua/luz transmitidas em tempo real para calculo de consumo
		* aplicativos para monitoramento remoto de pacientes
	* Pagamento Moveis: transações seguras via dispositivos (ex.: NFC, carteiras digitais)

### Impacto organizacionais
* Eficiência Operacional: automatização de processos (ex.: ETL em BI)
* Inovação: novos modelos de negócios (ex.: comercio baseado em dados de redes sociais)
* Tomada de decisões: Dashboards em BI permitem ações ágeis com base em dados históricos e preditivos 

### Conclusão 
As tecnologias de BI, IA e computação móvel estão revolucionando a gestão empresarial. Em quanto BI transforma dados em decisões estratégicas, a IA e a ciência de dados permitem analise complexas e inovação. Já a computação móvel amplia a acessibilidade e a agilidade dos serviços. Profissionais qualificados nessa área são essenciais para impulsionar a competitividade, exigindo certificações e adaptação continua às tenências tecnológicas.
